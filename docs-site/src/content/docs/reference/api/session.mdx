## Session из модели

```python
session_auth(
    SessionModel,
    *,
    credentials=None,
    session=None,
    service,
    store=None,
    identity=None,
    name="session",
    clock=...,
) -> Auth
```

Передайте `credentials=` для login или `session=` для готовой session.

## Session из cookie

```python
session_cookie(
    "session_id",
    *,
    credentials,
    service,
    store=None,
    identity=None,
    name="session-cookie",
    clock=...,
) -> Auth
```

`clock` принимает callable без аргументов, возвращающий timezone-aware `datetime`; по умолчанию
`datetime.now(UTC)`. По нему вычисляется `expires_at` cookie из `Max-Age`/`Expires` и
проверяется активность сохранённой session.

## Аннотации модели

```python
Bearer()
RefreshToken()
ExpiresAt(leeway=...)
```

## Несколько мест запроса

| Маркер | Размещение |
|---|---|
| `Placed.query(name, secret=True)` | параметр query |
| `Placed.header(name, prefix="", secret=True)` | заголовок |
| `Placed.cookie(name, secret=True)` | одна кука |
| `Placed.cookies()` | каждая пара поля `Mapping[str, str]` отдельной кукой |

`Bearer()` равен `Placed.header("Authorization", prefix="Bearer ")`. Модель обязана нести хотя бы
одно размещение и не больше одного `Bearer`. Сессия с пустым размещаемым значением считается
непригодной.

## Store

```python
from eazy_sdk.auth.session import MemorySessionStore, SessionStore

MemorySessionStore()
```

`MemorySessionStore` и protocol `SessionStore` живут в `eazy_sdk.auth.session`; из
`eazy_sdk.auth` они не экспортируются. Совместимый `SessionStore` получает новую session после
login или refresh.

`session_auth(...)` требует ровно один источник: `credentials=` для автоматического login или
`session=` для готового значения. Session model должна иметь ровно один `Bearer()` field, не более
одного `RefreshToken()` и не более одного `ExpiresAt()`.

`session_cookie(...)` всегда получает credentials и извлекает named cookie из `Set-Cookie`
успешного login response. Service должен вызвать `.with_response(...)` и передать envelope через
`context.capture(...)`, чтобы runtime увидел response headers.

Store protocol:

```python
await store.load(key) -> StoredSession | None
await store.save(key, value, revision)
await store.invalidate(key, expected=None)
```

Revision является CAS proof. Store обязан отклонить сохранение поверх неожиданной более новой
revision.
