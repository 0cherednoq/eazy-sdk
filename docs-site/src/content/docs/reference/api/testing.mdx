## Проверить запрос без сети

`.prepare()` использует тот же bind/resolve/project/encode/crypto/sign pipeline, что и обычный
вызов, но останавливается перед handler send:

```python
from eazy_sdk import PrepareOptions

prepared = await sdk.users.create.prepare(
    body={"name": "Ada"},
    options=PrepareOptions(resolve_managed=False),
)

assert prepared.method == "POST"
assert prepared.target == "/users"
assert prepared.encoded_body == b'{"name":"Ada"}'
```

Pure mode (`resolve_managed=False`) не вызывает dependency/auth/protection/key providers,
middleware или rate limiter. Если операция без них не готова, вызывается
`PreparationIncompleteError` со списком requirements.

Full mode (`resolve_managed=True`) разрешает managed values через test providers. Protection cache
для preparation изолирован от рабочего client. Network send не выполняется в обоих режимах.

`PreparedCall` — immutable safe view. Secret headers, cookies, managed query values и private body
заменяются на `<redacted>`; secret encoded body не публикуется.

## Проверить фактический Zapros request

```python
from eazy_sdk.testing import RecordingHandler

handler = RecordingHandler(
    status=200,
    headers={"Content-Type": "application/json"},
    content=b'{"name":"Ada"}',
)

with StoreSdk.from_handler(handler=handler, base_url="https://api.test") as sdk:
    sdk.users.get_user(user_id=7)

handler.assert_count(1)
handler.assert_request(method="GET", url="https://api.test/users/7")
```

`AsyncRecordingHandler` предоставляет тот же API для `AsyncApi`. Оба класса наследуют Zapros
`BaseHandler`/`AsyncBaseHandler` и записывают request, полученный transport boundary; собственного
preparation algorithm у них нет.
