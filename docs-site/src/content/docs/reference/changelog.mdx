Полная запись каждого изменения хранится в
[`CHANGELOG.md`](https://github.com/0cherednoq/eazy-sdk/blob/master/CHANGELOG.md). Эта страница даёт
карту выпусков и не заменяет первичный файл.

## Ещё не выпущено

- Варианты ответа теперь ставят критерий содержимого выше точности статуса.
- Добавлен `PydollDriver` для `pydoll-python` 3.
- Все представления ответа получили `when=`; добавлены `Const`, `Payload` и `accept=`.
- `fallback=` обрабатывает ответ, который отклонили все кандидаты после разбора тела.

## Выпуски

|---|---|---|
| `0.2.0a7` | 2026-09-08 | Декларативная пагинация |

Проект использует Semantic Versioning и версии PEP 440. До стабильного выпуска ломающие изменения
разрешены между альфа-версиями и перечисляются в `CHANGELOG.md`.
