Полная запись каждого изменения хранится в
[`CHANGELOG.md`](https://github.com/0cherednoq/eazy-sdk/blob/master/CHANGELOG.md). Эта страница даёт
карту выпусков и не заменяет первичный файл.

## Ещё не выпущено

После `0.2.0a10` изменений пока нет.

## Выпуски

| Версия | Дата | Основная область изменений |
|---|---|---|
| `0.2.0a10` | 2026-10-09 | Исход вызова из адреса перехода (`Location`), сессия в нескольких местах запроса (`Placed`), селектор `Regex` и `FromCookie` |
| `0.2.0a9` | 2026-10-07 | Исправление: значения `Inject` больше не попадают в чужие слоты |
| `0.2.0a8` | 2026-10-07 | Один пакет `eazy-sdk-core`, критерии вариантов ответа, `Const` и `Payload`, `PydollDriver` |
| `0.2.0a7` | 2026-09-08 | Декларативная пагинация |
| `0.2.0a6` | 2026-09-08 | Проверка фазы 50, производительность сериализации и пространство `Body` |
| `0.2.0a5` | 2026-09-05 | Транспортная идентичность, прокси и состояние защит |
| `0.2.0a4` | 2026-09-03 | Порты `SolveContext` и привязка защит к транспортной идентичности |
| `0.2.0a1` | 2026-09-02 | Проверенный SPI расширений и справочник автора SDK |
| `0.1.0` | 2026-09-01 | Снимок только в GitHub; ошибочно помечен стабильным и не опубликован в PyPI |
| `0.1.0a1` | 2026-08-25 | Первая публичная альфа |

Проект использует Semantic Versioning и версии PEP 440. До стабильного выпуска ломающие изменения
разрешены между альфа-версиями и перечисляются в `CHANGELOG.md`.
