## Контракт

```python
from pydantic import BaseModel

from eazy_sdk.response import ApiError, Error, Json, Responses, Success

class LoginProblem(BaseModel):
    code: str
    message: str

class InvalidPasswordError(ApiError[LoginProblem]):
    pass

class UserNotFoundError(ApiError[LoginProblem]):
    pass

responses = Responses(
    success=(Success(200, Json(UserSession)),),
    errors=(
        Error(401, Json(LoginProblem), exception=InvalidPasswordError),
        Error(404, Json(LoginProblem), exception=UserNotFoundError),
    ),
)
```

## Обработка

```python
request: LoginRequest = {
    "username": "ada@example.test",
    "password": "wrong",
}

try:
    session = await sdk.auth.login(request=request)
except InvalidPasswordError as exc:
    print(exc.error.message)
except UserNotFoundError as exc:
    print(exc.error.message)
```

`ApiError` хранит typed payload в `.error` и response context в `.context`. Не используйте status
code branching после обычного вызова: documented error case уже выбрал точный exception type.

Ответ с неизвестным status/media type даёт `UnexpectedResponseError`. Валидный case с malformed
payload даёт `MalformedResponseError`. Эти ошибки означают нарушение контракта upstream и не
смешиваются с ожидаемыми `401`/`404`.
