`parse_html` извлекает typed model без HTTP и без Zapros. Один schema contract работает с
dataclass, Pydantic и msgspec; selector engine возвращает primitive tree, после чего выбранный
`ModelAdapter` строит итоговый объект.

```python
from dataclasses import dataclass
from typing import Annotated

from eazy_sdk_html import CSS, Scope, parse_html

@dataclass
class Product:
    name: Annotated[str, CSS(".name::text")]
    price: Annotated[float, CSS(".price::text")]

@dataclass
class Catalog:
    title: Annotated[str, CSS("h1::text")]
    products: Annotated[list[Product], Scope(CSS("article.product"))]

catalog = parse_html(html_bytes, Catalog)
```

Используйте `CSS("a::attr(href)")` для атрибутов и `XPath("//h1/text()")`, когда XPath точнее.
Для `list[T]` selector возвращает все совпадения; для nested model `Scope(...)` создаёт отдельный
контекст на каждый найденный элемент. У optional field отсутствие совпадения даёт `None`, а у
required field — `ExtractionError` с полным model path и selector.

## HTML response

Тот же schema — это тип результата операции: объявлять семью ответа не нужно, её называет модель.

```python
from dataclasses import dataclass

from eazy_sdk import Http, HttpOperation, Path, SyncApi, op

@dataclass(frozen=True, slots=True, kw_only=True)
class GetCatalogue(HttpOperation[Catalog]):
    __http__ = Http.get("/catalogue/page-{page}.html")

    page: Path[int]

class BooksApi(SyncApi):
    catalogue = op(GetCatalogue)
```

`Catalog` несёт CSS-селекторы, поэтому ответ читает документный бэкенд: extractor → primitive tree
→ `ModelAdapter`. Модель без селекторов на том же месте читалась бы как JSON. Явный `Html(Model)`
нужен там, где задан особый медиа-тип или статус; для нестандартного формата реализуйте
`ResponseExtractor`, а `Parsed(...)` остаётся явным parser escape hatch для протоколов, которые не
выражаются extractor schema.

Документная модель, у которой нет ни одного обязательного поля, подошла бы к любой странице —
включая страницу ошибки, стоящую рядом в том же наборе случаев. Такая операция отвергается при
компиляции: добавьте обязательное поле-селектор или условие `when=`.

## Парсер выбирается на корне

Селекторы — контракт операции; парсер, который строит документ, — реализация, поэтому он
объявляется один раз:

```python
from eazy_sdk.serialization import Serialization

store = Store(client, serialization=Serialization(documents=(ParselBackend(),)))
```

По умолчанию используется parsel, который читает и CSS, и XPath. Бэкенды не взаимозаменяемы по
языку селекторов, и это проверяется **при компиляции**: операция с `XPath(...)` на парсере без
XPath отвергается с указанием поля, языка и бэкенда, а не даёт пустое извлечение в рантайме —
пустой результат выглядел бы как «сервер перестал присылать поле».
