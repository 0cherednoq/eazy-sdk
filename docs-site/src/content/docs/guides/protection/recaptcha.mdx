v2/checkbox policies реагируют на response challenge. v3/action и Enterprise score policies
получают token до request.

```python target
v2 = recaptcha.v2_checkbox(
    scope=operation("login"),
    apply=form_field("g-recaptcha-response"),
)

v3 = recaptcha.v3_action(
    scope=operation("createAccount"),
    site_key="public-site-key",
    action="create_account",
    apply=form_field("g-recaptcha-response"),
)

config = ClientConfig(
    challenge_policies=(v2,),
    before_call_policies=(v3,),
    challenge_solvers=ChallengeSolverBindings(
        bind_challenge_solver(v2.solver, RecaptchaV2Solver()),
        bind_challenge_solver(v3.solver, RecaptchaV3Solver()),
    ),
)
```

`scope=operation(...)` ограничивает policy одной operation identity. Solver возвращает typed
solution и не мутирует request, cache или retry coordinator. Private token field отсутствует в
public method signature и добавляется перед projection/encoding/signing нужного attempt.
