## Preset

```python
from datetime import datetime

from eazy_sdk import Client, ClientConfig
from eazy_sdk_presets import cloudflare, host

class CloudflareSolver:
    async def solve(self, challenge, context):
        return cloudflare.CloudflareClearance(
            cookies=(
                cloudflare.SecretCookie("cf_clearance", "clearance-value"),
            ),
            expires_at=datetime.fromisoformat("2030-01-01T00:00:00+00:00"),
        )

protection = cloudflare.challenge_pages(
    scope=host("api.example.test"),
    solver=CloudflareSolver(),
)

client = Client(
    base_url=base_url,
    handler=handler,
    config=ClientConfig(protections=(protection,)),
)
```

Замените пример solver реализацией вашего captcha-сервиса или браузерного адаптера.
