Widget и preclearance принадлежат разным lifecycle и поэтому подключаются в разные config fields.

```python target
widget = cloudflare.turnstile_widget(
    scope=operation("login"),
    apply=form_field("cf-turnstile-response"),
)

preclearance = cloudflare.turnstile_preclearance(
    scope=host("api.example.test"),
    site_key="public-site-key",
    page_url="https://api.example.test/login",
)

config = ClientConfig(
    challenge_policies=(widget,),
    before_call_policies=(preclearance,),
    challenge_solvers=ChallengeSolverBindings(
        bind_challenge_solver(widget.solver, TurnstileTokenSolver()),
        bind_challenge_solver(preclearance.solver, TurnstileClearanceSolver()),
    ),
)
```

Widget решается только после matched response и использует replay safety. Preclearance решается до
origin request, переиспользуется до expiry и привязан к network identity.
