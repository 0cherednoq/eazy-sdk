`Form()` описывает отдельное поле `application/x-www-form-urlencoded`. Это удобно для HTML login
и OAuth-style token endpoints.

```python
from typing import Annotated, NotRequired, TypedDict, Unpack

from eazy_sdk import AsyncApi, api
from eazy_sdk.request import Form

class LoginRequest(TypedDict):
    email: Annotated[str, Form()]
    password: Annotated[str, Form()]
    remember: NotRequired[Annotated[bool, Form()]]

class AsyncAuthApi(AsyncApi):
    @api.post("/login", operation_id="login", responses=RESPONSES)
    async def login(self, **request: Unpack[LoginRequest]) -> Session:
        raise NotImplementedError
```

Запрос: `POST /login`, `Content-Type: application/x-www-form-urlencoded`, body
`email=ada%40example.test&password=secret`. Отсутствующее optional поле `remember` не попадает в body.

Для полной Pydantic-модели используйте `FormBody()`. Не смешивайте `FormBody()` и отдельные
`Form()` fields. Порядок полей при необходимости задаётся через `WireOptions(body_order=(...))`.
Пример ответа: status `200`, JSON `{"access_token":"..."}`.
