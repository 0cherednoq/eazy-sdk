`Form()` описывает отдельное поле `application/x-www-form-urlencoded`. Это удобно для HTML login
и OAuth-style token endpoints.

```python
from dataclasses import dataclass

from eazy_sdk import UNSET, AsyncApi, Http, HttpOperation, Omittable, op
from eazy_sdk.request import Form

@dataclass(frozen=True, slots=True, kw_only=True)
class Login(HttpOperation[Session]):
    __http__ = Http.post("/login", operation_id="login")

    email: Form[str]
    password: Form[str]
    remember: Form[Omittable[bool]] = UNSET

class AsyncAuthApi(AsyncApi):
    login = op(Login)
```

Запрос: `POST /login`, `Content-Type: application/x-www-form-urlencoded`, body
`email=ada%40example.test&password=secret`. Поле `remember`, оставшееся `UNSET`, в body не попадает.

Для полной Pydantic-модели используйте `FormBody()`. Не смешивайте `FormBody()` и отдельные
`Form()` fields. Порядок полей при необходимости задаётся через `wire=Wire(order=FieldOrder(body=(...)))`
в `__http__`.
Пример ответа: status `200`, JSON `{"access_token":"..."}`.
