Каждое поле единого operation `TypedDict` занимает одно явное место в HTTP request. Метод раскрывает
schema через `**request: Unpack[OperationRequest]`. Eazy SDK проверяет placements при создании
API-класса, до middleware и сети.

| Часть запроса | Marker | Руководство |
|---|---|---|
| URL placeholder | `Annotated[T, Path()]` | {doc}`Path </guides/requests/path>` |
| Query parameter | `Annotated[T, Query()]` | {doc}`Query </guides/requests/query>` |
| Header | `Annotated[T, Header()]` | {doc}`Headers </guides/requests/headers>` |
| Cookie | `Annotated[T, Cookie()]` | {doc}`Cookies </guides/requests/cookies>` |
| JSON document | `Annotated[TypedDict | Model, JsonBody()]` | {doc}`JSON body </guides/requests/json>` |
| Form field | `Annotated[T, Form()]` | {doc}`Form body </guides/requests/form>` |
| Multipart part | `Annotated[T, Part()]` | {doc}`Multipart </guides/requests/multipart>` |
| Готовые bytes | `Annotated[bytes, BytesBody()]` | {doc}`Bytes </guides/requests/bytes>` |

Весь плоский request описывайте одним `TypedDict`, включая path, query, headers, cookies и body
fields. Pydantic/dataclass/msgspec нужны для вложенного document или model-owned
validation/serialization policy; такая модель остаётся значением одного поля request-`TypedDict`.
`Unpack` сохраняет точную IDE и strict-type-checker сигнатуру без повторения полей в методе.

Один параметр нельзя разместить дважды. Placeholder path должен иметь ровно один `Path` marker.
`options` зарезервирован для `CallOptions | None`, должен быть keyword-only и не попадает в HTTP.
