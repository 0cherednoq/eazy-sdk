Header marker связывает Python-аргумент с request header. Указывайте wire-имя явно, когда оно
отличается от имени аргумента.

```python
from dataclasses import dataclass
from typing import Annotated

from eazy_sdk import UNSET, Http, HttpOperation, Omittable, SyncApi, op
from eazy_sdk.request import markers

@dataclass(frozen=True, slots=True, kw_only=True)
class GetReport(HttpOperation[Report]):
    __http__ = Http.get("/reports", operation_id="getReport")

    locale: Annotated[str, markers.Header("Accept-Language")] = "en"
    request_id: Annotated[Omittable[str], markers.Header("X-Request-ID")] = UNSET

class ReportsApi(SyncApi):
    report = op(GetReport)
```

`report(locale="ru")` отправит `Accept-Language: ru` и пропустит `X-Request-ID`: `UNSET` не
уходит на провод.
Header names сравниваются без учёта регистра, но Eazy SDK сохраняет объявленное wire-имя и порядок
там, где transport поддерживает exact mode.

Не передавайте authorization, signing или managed protection headers вручную. Они принадлежат
client policy и добавляются до отправки. Пример ответа: status `200`, header
`Content-Type: application/json`, body `{"ready":true}`.
