Cookie marker подходит для значения, которое действительно является аргументом операции. Session
cookie лучше подключать через auth policy.

```python
from dataclasses import dataclass
from typing import Annotated

from eazy_sdk import UNSET, Http, HttpOperation, Omittable, SyncApi, op
from eazy_sdk.request import markers

@dataclass(frozen=True, slots=True, kw_only=True)
class GetDashboard(HttpOperation[Dashboard]):
    __http__ = Http.get("/dashboard", operation_id="dashboard")

    experiment: Annotated[Omittable[str], markers.Cookie("experiment")] = UNSET

class DashboardApi(SyncApi):
    dashboard = op(GetDashboard)
```

`dashboard(experiment="new-nav")` отправит `Cookie: experiment=new-nav`. Поле, оставшееся `UNSET`,
cookie не добавляет. Несколько cookie объединяются в один корректный header на этапе preparation.

Для готовой auth cookie используйте `CookieScheme`; для cookie из login response используйте
`session_cookie(...)`. Тогда credential не появляется в сигнатуре метода. Пример ответа: status
`200`, `Content-Type: application/json`, body `{"widgets":3}`.
