Каждый `Part()` становится частью `multipart/form-data`. Для filename, part content type или
собственных part headers передайте `MultipartPart`.

```python
from dataclasses import dataclass
from typing import Annotated

from eazy_sdk import UNSET, Http, HttpOperation, Omittable, SyncApi, op
from eazy_sdk.request import MultipartPart, Part, markers

@dataclass(frozen=True, slots=True, kw_only=True)
class UploadFile(HttpOperation[Upload]):
    __http__ = Http.post("/files", operation_id="uploadFile")

    document: Annotated[MultipartPart, markers.Part("document")]
    label: Part[Omittable[str]] = UNSET

class FilesApi(SyncApi):
    upload = op(UploadFile)

result = FilesApi(client).upload(
    document=MultipartPart(
        b"PNG bytes",
        filename="avatar.png",
        content_type="image/png",
    ),
)
```

Eazy SDK формирует boundary и framing bytes до отправки. Для фиксированного boundary или полного
body model используйте `MultipartBody(boundary=...)`. Adapter получает уже подготовленные bytes и
не пересобирает multipart.

Пример ответа: status `201`, `Content-Type: application/json`, body `{"file_id":"f-1"}`.
