Dependency подходит для device context, tenant ID и других значений, которые получает service, а
не caller операции. Descriptor задаёт result type, cache policy и bindings; implementation
регистрируется отдельно в `DependencyRegistry`.

```python
from typing import Annotated, TypedDict, Unpack

from eazy_sdk import AsyncApi, api
from eazy_sdk.request import JsonBody

class CreatePaymentRequest(TypedDict):
    body: Annotated[Payment, JsonBody()]

class PaymentsApi(AsyncApi):
    @api.post("/payments", responses=RESPONSES, requires=(DEVICE_SPEC,))
    async def create(self, **request: Unpack[CreatePaymentRequest]) -> Receipt:
        raise NotImplementedError
```

`field(name)` выбирает атрибут результата, `value()` — весь результат. Target может быть header,
query, cookie или body. Cache policies: `NONE`, `CLIENT`, `CALL`, `ATTEMPT`. Dependency patch
проверяется атомарно до request side effects.

Регистрируйте implementation в identity вызывающей стороны, а не в операции:

```python
from eazy_sdk import Identity
from eazy_sdk.dependencies import DependencyRegistry

dependencies = DependencyRegistry()
dependencies.register(DEVICE_SPEC, load_device_context)
identity = Identity(dependencies=dependencies)
```

| Cache policy | Повторное вычисление |
|---|---|
| `NONE` | Каждый resolver access |
| `CLIENT` | Один раз на lifetime роутера |
| `CALL` | Один раз на logical API call |
| `ATTEMPT` | Для каждой retry/redirect attempt |

Если required dependency не зарегистрирована или возвращает значение неверного типа, вызов
завершается до сети. Resolver не получает mutable request и не может обойти signing.

Пример request после binding: header `X-Device-ID: device-7`, JSON
`{"amount":"49.90","device":{"locale":"ru"}}`; response status `201`, JSON
`{"id":"pay_42"}`.
