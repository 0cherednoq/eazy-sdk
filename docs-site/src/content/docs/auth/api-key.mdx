::::{tab-set}
  :::{tab-item} Header

```python
from eazy_sdk.auth import ApiKeyScheme

API_KEY = ApiKeyScheme.header("X-API-Key", name="reporting-key")
auth = API_KEY.static("key_demo_123")
```
:::
  :::{tab-item} Query

```python
from eazy_sdk.auth import ApiKeyScheme

API_KEY = ApiKeyScheme.query("api_key", name="weather-key")
auth = API_KEY.static("key_demo_123")
```

Query-вариант отправит `/weather?api_key=key_demo_123`.
:::
::::

Передайте `auth` в `ClientConfig` и укажите `security=API_KEY` в декораторе операции:

```python
from eazy_sdk import Client, ClientConfig, SyncApi, api
from eazy_sdk.handlers.httpx import HttpxHandler

class ReportsApi(SyncApi):
    @api.get("/reports", responses=REPORT_RESPONSES, security=API_KEY)
    def reports(self) -> Reports:
        raise NotImplementedError

client = Client(
    base_url="https://api.example",
    handler=HttpxHandler(raw, owns_client=True),
    config=ClientConfig(auth=auth),
)
reports = ReportsApi(client).reports()
```

Не передавайте API key аргументом метода. Это credential клиента, а не часть публичной сигнатуры
операции. Missing provider завершается до отправки HTTP request.
