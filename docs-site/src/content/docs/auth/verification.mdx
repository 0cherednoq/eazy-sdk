```python
from pydantic import BaseModel, SecretStr

from eazy_sdk.accounts import PendingRegistration, VerificationAccepted

class VerificationCode(BaseModel):
    code: SecretStr

class RegistrationService:
    async def verify(self, account, challenge, proof, api):
        code = VerificationCode.model_validate(proof)
        response = await api.accounts.verifyAccount(
            verification_id=challenge.id,
            code=code.code.get_secret_value(),
        )
        return VerificationAccepted(session=response.session)

if isinstance(result, PendingRegistration):
    result = await registrations.verify(
        result,
        VerificationCode(code="123456"),
    )
```

После успешного verification registration store сохраняет новый статус аккаунта и session из
ответа. Неверный proof оставляет регистрацию в pending-состоянии.

После перезапуска загрузите незавершённую регистрацию по identifier:

```python
pending = await registrations.resume("ada@example.test")
```
