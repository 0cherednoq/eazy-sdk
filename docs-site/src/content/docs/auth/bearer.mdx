Используйте статический Bearer token, если приложение уже получило access token и не должно
автоматически выполнять login или refresh.

```python
import httpx

from eazy_sdk import AsyncApi, AsyncClient, ClientConfig, api
from eazy_sdk.auth import BearerScheme
from eazy_sdk.handlers.httpx import AsyncHttpxHandler

BEARER = BearerScheme("user-bearer")

class AsyncAccountApi(AsyncApi):
    @api.get("/account", responses=ACCOUNT_RESPONSES, security=BEARER)
    async def get_account(self) -> Account:
        raise NotImplementedError

auth = BEARER.static("access-v1")
client = AsyncClient(
    base_url="https://api.example.test",
    handler=AsyncHttpxHandler(httpx.AsyncClient(), owns_client=True),
    config=ClientConfig(auth=auth),
)
account = await AsyncAccountApi(client).get_account()
await client.aclose()
```

Имя схемы является диагностическим identity и должно быть стабильным в пределах SDK. Для token,
который нужно получать и обновлять автоматически, используйте {doc}`Login </auth/login>` и
{doc}`Refresh </auth/refresh>`.
