Credentials содержат данные для будущего login. Profile содержит данные аккаунта. Details нужны
только во время регистрации.

```python
from typing import Annotated

from pydantic import BaseModel, SecretStr

from eazy_sdk_accounts import (
    AccountCreated,
    AccountDraft,
    AccountIdentifier,
    MemoryRegistrationStore,
    VerificationChallenge,
    account_registration,
)

class SignupCredentials(BaseModel):
    email: Annotated[str, AccountIdentifier()]
    password: SecretStr

class AccountProfile(BaseModel):
    first_name: str

class SignupDetails(BaseModel):
    accepted_terms: bool

class CredentialsCodec:
    def encode(self, value: SignupCredentials) -> object:
        return {
            "email": value.email,
            "password": value.password.get_secret_value(),
        }

    def decode(self, value: object) -> SignupCredentials:
        return SignupCredentials.model_validate(value)

class RegistrationService:
    async def create(self, draft, api):
        response = await api.accounts.createAccount(
            email=draft.credentials.email,
            password=draft.credentials.password.get_secret_value(),
            first_name=draft.profile.first_name,
            accepted_terms=draft.details.accepted_terms,
        )
        return AccountCreated(
            remote_id=response.user_id,
            verification=VerificationChallenge(
                id=response.verification_id,
                kind=response.verification_kind,
            ),
        )

registrations = account_registration(
    SignupCredentials,
    service=RegistrationService(),
    store=MemoryRegistrationStore(CredentialsCodec()),
    context_factory=lambda: api,
    provider="example.test",
)

result = await registrations.create(
    AccountDraft(
        credentials=SignupCredentials(
            email="ada@example.test",
            password="correct-horse",
        ),
        profile=AccountProfile(first_name="Ada"),
        details=SignupDetails(accepted_terms=True),
    )
)
```

Успешный create автоматически сохраняется через переданный registration store. Если сервер вернул
challenge, `result` будет `PendingRegistration`. Следующий шаг описан в
{doc}`Verification </auth/verification>`.
