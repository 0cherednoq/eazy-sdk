За пять минут соберём метод SDK интернет-магазина: запросим товар по ID и получим проверенный
`Product`.

## Установите Eazy SDK

```bash
uv add "eazy-sdk[httpx,pydantic]"
```

## Создайте `quickstart.py`

```python
from dataclasses import dataclass

import httpx
from pydantic import BaseModel

from eazy_sdk import Client, Http, HttpOperation, Path, SyncApi, op

class Product(BaseModel):
    id: int
    title: str
    price: int

@dataclass(frozen=True, slots=True, kw_only=True)
class GetProduct(HttpOperation[Product]):
    __http__ = Http.get("/v1/products/{product_id}")

    product_id: Path[int]

class StoreApi(SyncApi):
    product = op(GetProduct)

def store(request: httpx.Request) -> httpx.Response:
    assert request.url.path == "/v1/products/42"
    return httpx.Response(
        200,
        json={"id": 42, "title": "Mechanical keyboard", "price": 12900},
    )

with Client.httpx(
    base_url="https://api.store.example",
    transport=httpx.MockTransport(store),
) as client:
    product = StoreApi(client).product(product_id=42)
    print(product.title, product.price)
```

`MockTransport` изображает сервер, поэтому пример работает без сети. В SDK уберите `transport=`:
`Client.httpx()` сам создаст `httpx.Client`, а `Client(base_url=...)` без аргументов использует
стандартный сетевой handler Zapros.

## Запустите

```bash
uv run python quickstart.py
```

```text
Mechanical keyboard 12900
```

Операция — это класс. `Path[int]` подставил `42` в URL, а `HttpOperation[Product]` сказал, что
успешный ответ — это `Product`: семья ответа выведена из модели, объявлять `Json(...)` не нужно.
`op(GetProduct)` публикует класс на роутере, и `store.product(...)` показывает в IDE ровно
конструктор класса — с типами полей и их значениями по умолчанию.

Тот же метод можно объявить декоратором — это короткая форма того же самого класса:

```python
from typing import Annotated

from eazy_sdk import SyncApi, api
from eazy_sdk.request import markers

class StoreApi(SyncApi):
    @api.get("/v1/products/{product_id}")
    def product(self, *, product_id: Annotated[int, markers.Path()]) -> Product:
        raise NotImplementedError
```

Декоратор синтезирует тот же frozen-класс: `StoreApi.product.Operation` — это он. Пишите
return-аннотацию у каждой декларации (объявление проходит `mypy --strict` без отключения
`no-untyped-def`) и оставляйте `raise NotImplementedError` в теле: runtime его не вызывает, а
`...` mypy считает ошибкой `empty-body`.

`api` содержит стандартные HTTP-декораторы, включая `head`, `options` и `trace`;
`api.request(method, ...)` принимает другой валидный HTTP token. У класса тот же набор:
`Http.get`, `Http.post`, ..., `Http.request(method, path)`.

Для POST/PUT объявите поля тела маркером `JsonField` — они станут полями того же класса, с
обычными Python-значениями по умолчанию. Если внешний API требует nested JSON, не добавляйте
caller-у wrapper dict: `BodyProjection` связывает поля операции с private wire schema и повторяет
mapping/validation/encoding на каждой retry или redirect attempt.

Один роутер живёт прямо на клиенте: `StoreApi(client)`. Когда роутеров несколько, соберите их
в корень `SyncRoot`/`AsyncRoot` через `api_group(...)`; адрес каждого сервиса при этом объявляет
сам роутер — см. {doc}`Мультисервисный SDK </guides/multi-service>`.

Продолжите со {doc}`сквозным примером SDK магазина </more/examples/store-sdk>`. Там этот метод вырастает
в клиент с JSON body, ошибками API, авторизацией, подписью, шифрованием и WebSocket.
