```python
from curl_cffi import requests

from eazy_sdk import AsyncClient
from eazy_sdk.handlers.curl_cffi import AsyncCurlCffiZaprosHandler

raw = requests.AsyncSession()
client = AsyncClient(
    base_url="https://api.example",
    handler=AsyncCurlCffiZaprosHandler(raw, owns_session=True),
)
users = AsyncUsersApi(client)
user = await users.get_user(user_id=42)
await client.aclose()
```

Sync-вариант использует `requests.Session` и `SyncUsersApi`. Impersonation, TLS fingerprint и proxy
принадлежат transport/session configuration; typed API остаётся тем же. Короткая форма
`AsyncClient.curl_cffi(base_url=..., impersonate="chrome", proxy="http://proxy:8080")` создаёт
сессию сама и объявляет `impersonate`/`proxy` в `HandlerProfile`, чтобы managed clearance была
привязана к этой identity.

Если operation требует exact wire capability, adapter проверит её до dependency resolver и сети.
