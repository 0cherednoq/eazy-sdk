Первому JSON SDK нужны ядро, HTTPX и поддержка моделей Pydantic. Установите их командой
`uv add "eazy-sdk[httpx,pydantic]"`.

Команда добавляет синхронный и асинхронный адаптер HTTPX. Само ядро не выбирает HTTP-клиент и
библиотеку моделей за приложение.

В проекте с pip набор зависимостей остаётся тем же:
`python -m pip install "eazy-sdk[httpx,pydantic]"`.

## Выберите нужные дополнения

Не устанавливайте полный набор для каждой задачи. Добавьте только транспорт, формат данных или
интеграцию, которые нужны SDK.

| Задача | Пакет или дополнение | Команда для uv |
|---|---|---|
| HTTP через HTTPX | `eazy-sdk[httpx]` | `uv add "eazy-sdk[httpx]"` |
| Синхронный HTTP через Requests | `eazy-sdk[requests]` | `uv add "eazy-sdk[requests]"` |
| HTTP через curl_cffi | `eazy-sdk[curl-cffi]` | `uv add "eazy-sdk[curl-cffi]"` |
| Модели Pydantic v2 | `eazy-sdk[pydantic]` | `uv add "eazy-sdk[pydantic]"` |
| Модели msgspec Struct | `eazy-sdk[msgspec]` | `uv add "eazy-sdk[msgspec]"` |
| Разбор HTML | `eazy-sdk[html]` | `uv add "eazy-sdk[html]"` |
| Аккаунты и регистрация | `eazy-sdk[accounts]` | `uv add "eazy-sdk[accounts]"` |
| Хранилище SQLModel | `eazy-sdk[sqlmodel]` | `uv add "eazy-sdk[sqlmodel]"` |
| WebSocket | `eazy-sdk[websocket]` | `uv add "eazy-sdk[websocket]"` |
| Браузерный SDK с Playwright | `eazy-sdk-browser[playwright]` | `uv add "eazy-sdk-browser[playwright]"` |
| Генератор OpenAPI | `eazy-sdk-openapi[yaml]` | `uv add "eazy-sdk-openapi[yaml]"` |
| Генератор AsyncAPI | `eazy-sdk-asyncapi[yaml]` | `uv add "eazy-sdk-asyncapi[yaml]"` |
| Готовые описания защит | `eazy-sdk-presets` | `uv add eazy-sdk-presets` |
| XML | `eazy-sdk-xml` | `uv add eazy-sdk-xml` |
| Модели Adaptix | `eazy-sdk-adaptix` | `uv add eazy-sdk-adaptix` |

Дополнение `[yaml]` у генераторов нужно для файлов YAML. Для спецификации JSON достаточно пакета
без этого дополнения. У браузерного пакета вместо `playwright` можно выбрать `selenium`,
`camoufox` или `pydoll`.

`eazy-sdk[all]` ставит основные HTTP-интеграции, модели и средства работы с данными, но
намеренно не ставит браузерный драйвер. Браузер и его двоичные файлы выбирает приложение.

## Проверьте установку

В проекте с uv запустите
`uv run python -c "import eazy_sdk, httpx, pydantic; print(eazy_sdk.__version__)"`.
В активированном окружении pip уберите префикс `uv run` и начните команду с `python`.

Результат содержит только установленную версию:

```text
0.2.0a7
```

Если вы выбрали другой HTTP-клиент или библиотеку моделей, замените `httpx` и `pydantic` в
строке импорта. Трассировки ошибки быть не должно.

## Требования

- Python 3.13 или новее.
- Менеджер пакетов с поддержкой дополнений Python. Команды выше даны для uv и pip.
- Один поддерживаемый HTTP-клиент для HTTP SDK. Список возможностей клиентов находится в
  {doc}`руководстве по HTTP-интеграциям </integrations/http/index>`.
- Драйвер для браузерного SDK. После установки Playwright загрузите Chromium командой
  `uv run playwright install chromium`. В активированном окружении pip используйте
  `playwright install chromium`.
