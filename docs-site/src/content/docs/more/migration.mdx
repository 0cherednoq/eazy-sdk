Eazy SDK в альфе переименовывает без deprecated-алиасов: старое имя исчезает, `ImportError`
или `AttributeError` показывает, что именно нужно поменять. Эта страница — единственная
подсказка. Каждая строка таблицы проверяется тестом: «стало» импортируется, «было» отсутствует.

## 0.2.0a5 → 0.3.0

Корень SDK стал отдельным типом. `SyncApi`/`AsyncApi` — это роутер: операции и атрибуты сервиса
(`base_url`, `errors`, `security`, `signing`, `crypto`, `wire`, `signed`, `allow`). Композиция,
владение клиентами и привязки живут в `SyncRoot`/`AsyncRoot`; `api_group(...)` объявляется только
на корне. Подробности — {doc}`Мультисервисный SDK </guides/multi-service>`.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.SyncApi.from_handler` | `eazy_sdk.SyncRoot.from_handler` | Фабрика переехала на корень; она же создаёт и закрывает свой клиент. |
| `eazy_sdk.AsyncApi.from_handler` | `eazy_sdk.AsyncRoot.from_handler` | То же для async. |
| `eazy_sdk.SyncApi.from_client` | `eazy_sdk.SyncRoot` | Второго способа собрать корень нет: `ShopSdk(client)` — обычный конструктор. |
| `eazy_sdk.AsyncApi.from_client` | `eazy_sdk.AsyncRoot` | То же для async. |
| `eazy_sdk.SyncApi.close` | `eazy_sdk.SyncRoot.close` | Роутер ничем не владеет; закрывает ресурсы корень. |
| `eazy_sdk.AsyncApi.aclose` | `eazy_sdk.AsyncRoot.aclose` | То же для async. |
| `eazy_sdk.ApiDefaults` | `eazy_sdk.SyncApi` | Дефолты роутера стали обычными атрибутами класса и наследуются по MRO. |

Аутентификация уехала из транспорта в session scope. `Identity` объявляет auth-схемы, ключи
подписи, DI и observer; он передаётся корню (`ShopSdk(client, identity=…)`) или отдельному роутеру
(`UsersApi(client, identity=…)`). Один `Identity` обслуживает все сервисы корня — и когда они делят
клиент, и когда у каждого свой.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.ClientConfig.auth` | `eazy_sdk.Identity.auth` | Кортеж настроенных `Auth`; `session_auth(...)`/`SessionScheme.configure(...)` не изменились. |
| `eazy_sdk.ClientConfig.key_provider` | `eazy_sdk.Identity.key_provider` | Алгоритм подписи — контракт API, ключ — секрет вызывающей стороны. |
| `eazy_sdk.ClientConfig.dependencies` | `eazy_sdk.Identity.dependencies` | DI зависит от окружения вызова, а не от пула соединений. |
| `eazy_sdk.ClientConfig.observer` | `eazy_sdk.Identity.observer` | Наблюдатель следует за вызывающей стороной. |
| `eazy_sdk.Client.bind_sdk` | `eazy_sdk.Identity` | Фабрику scoped SDK регистрирует тот, кому передан `identity=`. |

Корень `eazy_sdk` экспортирует 39 имён вместо 55: то, что нужно автору SDK в первый час. Всё
остальное импортируется из своего модуля — это не сокрытие, а отказ от второго имени для одной
вещи.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.ModelAdapter` | `eazy_sdk.models.ModelAdapter` | Вместе с `ModelAdapterRegistry`, `ModelField`, `default_model_adapters` и ошибками адаптеров. |
| `eazy_sdk.BodyCodec` | `eazy_sdk.codecs.BodyCodec` | Вместе с `ScalarCodec` и `DelimitedScalarCodec`. |
| `eazy_sdk.PlanError` | `eazy_sdk.core.errors.PlanError` | Вместе с `BindingError`, `GraphError`, `PatchError`, `OperationBindingError`. |
| `eazy_sdk.UnsafeReplayError` | `eazy_sdk.clients.UnsafeReplayError` | Вместе с `AttemptLimitError` и `RedirectLimitError`. |
| `eazy_sdk.CapabilityMismatchError` | `eazy_sdk.handlers.CapabilityMismatchError` | |
| `eazy_sdk.MiddlewareProtocolError` | `eazy_sdk.middleware.MiddlewareProtocolError` | |
| `eazy_sdk.PreparationIncompleteError` | `eazy_sdk.preparation.PreparationIncompleteError` | Вместе с `PreparedValue`. |
| `eazy_sdk.ResponseExtractor` | `eazy_sdk.response.ResponseExtractor` | Вместе с `AmbiguousResponseError` и `MalformedResponseError`. |
| `eazy_sdk.core.ports.CryptoProfile` | `eazy_sdk.compile.http_compiler.CryptoProfile` | Порт переехал к единственному читателю; слоя ради разрыва импорта больше нет. |

Синхронный клиент больше не создаёт event loop: тот же конвейер шагается на вызывающем потоке.
`Client` теперь можно вызывать из кода, где loop уже работает; взамен колбэк, который сам уходит
в сеть через `await`, поднимает `SynchronousSuspensionError` вместо того, чтобы молча крутиться в
приватном loop.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.clients.EventLoopConflictError` | `eazy_sdk.clients.SynchronousSuspensionError` | Ошибка сменила причину: не «loop уже работает», а «этот колбэк действительно приостанавливается». |

`ClientConfig` перестал быть плоским списком из пятнадцати полей: остались три группы по владельцу
плюс host-scoped `crypto` (его судьба решается в фазе 48). `guards=` понижается фабрикой
`Security.of(...)`, а не мутацией frozen-объекта в `__post_init__`.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.ClientConfig.retry` | `eazy_sdk.Resilience.retry` | Вместе с `auth_retries`, `max_redirects`, `timeout` и `rate_limiter`. |
| `eazy_sdk.ClientConfig.timeout` | `eazy_sdk.Resilience.timeout` | Валидация бюджетов переехала в группу. |
| `eazy_sdk.ClientConfig.rate_limiter` | `eazy_sdk.Resilience.rate_limiter` | |
| `eazy_sdk.ClientConfig.protection` | `eazy_sdk.Security.protection` | Пустой `ProtectionBundle` вместо `None`; `ClientConfig.bundle` не изменился. |
| `eazy_sdk.ClientConfig.guards` | `eazy_sdk.Security.of` | Публичного поля, которое всегда пусто, больше нет. |
| `eazy_sdk.ClientConfig.middleware` | `eazy_sdk.Hooks.middleware` | |
| `eazy_sdk.ClientConfig.models` | `eazy_sdk.Serialization.models` | Библиотека моделей — реализация SDK, объявляется на корне. |
| `eazy_sdk.ClientConfig.profile` | `eazy_sdk.request.Wire` | `WireProfile` был наполовину мёртв: фаза 48 заменила его контрактом представления на операции. |

Слово «wire» теперь означает ровно одно — представление запроса на проводе. Всё, что влияет на
байты, объявляется одним `Wire` на операции (и наследуется от роутера и миксина сервиса); всё, что
не влияет, — одним `Serialization` на корне. Подпись объявляется только по месту: адресных правил
`sign(scope=…)` больше нет, потому что опечатка в `hosts=` оставляла запрос молча неподписанным.
Подробности — {doc}`Представление запроса </guides/requests/representation>`.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.request.WireOptions` | `eazy_sdk.request.Wire` | `order=FieldOrder(query=…, header=…, cookie=…, body=…)`, `exact=`, `transport=`. |
| `eazy_sdk.request.SigningRule` | `eazy_sdk.request.hmac_sha256` | Подпись объявляет операция или роутер параметром `signing=`; scoped-правил нет. |
| `eazy_sdk.request.SigningOverride` | `eazy_sdk.SyncApi` | Переопределение — это объявление на более специфичном роутере. |
| `eazy_sdk.crypto.CryptoWire` | `eazy_sdk.crypto.Encrypted` | Тип шифрованного представления; у HTTP-операции это `wire=Wire(encrypted=…)`. |
| `eazy_sdk.crypto.CryptoRule.wire` | `eazy_sdk.crypto.CryptoRule.encrypted` | Одно имя для одного понятия и в HTTP, и в WebSocket: `ws.call(encrypted=…)` — тоже. |

Новое без замены: `eazy_sdk.serialization.Serialization(json=…, html=…)` — JSON-бэкенд и парсер
документов объявляются на корне, а бэкенд, не способный выполнить контракт операции, отвергается
при компиляции, а не молча меняет байты.

Понятие конверта уехало из транспорта: `Envelope`, `ProtocolMessage`, `CorrelationKey`,
`ChannelKey`, `ControlKind` и `InboundMessageKind` живут в `eazy_sdk.protocols` и описывают
протокол прикладного уровня, а не WebSocket. `WsProtocol` — это `Envelope` плюс то, что есть
только у соединения. Подробности — {doc}`Протоколы и конверты </guides/protocols>`.

| Было | Стало | Комментарий |
|---|---|---|
| `eazy_sdk.websocket.CorrelationKey` | `eazy_sdk.protocols.CorrelationKey` | Вместе с `ChannelKey`. |
| `eazy_sdk.websocket.ProtocolMessage` | `eazy_sdk.protocols.ProtocolMessage` | Вместе с `ControlKind` и `InboundMessageKind`. |

Новое без замены: `eazy_sdk.protocols.JsonRpc` и `@api.rpc("method")` — сервис, у которого имя
метода лежит в теле, описывается так же, как REST; `rpc_result`, `rpc_error(code, model)` и
`rpc_error_default(model)` строят обычные `Success`/`Error`, второй модели ошибок не появляется.
Реализация `WsProtocol` получает метод `read(envelope)` — прежняя логика `inspect(frame)` после
декодирования кадра.

Новое без замены: `eazy_sdk.bind` и `eazy_sdk.Binding` — привязка роутера или его миксина к
другому клиенту и/или адресу при сборке (`bindings=(...)`).

Операция стала классом. Поля класса — это поля запроса, `__http__` — всё, что операция объявляет,
а `op(...)` публикует её на роутере. Декоратор остался короткой формой того же самого: он
синтезирует такой же frozen-класс. Причина — не стиль: у `TypedDict` нет значений по умолчанию и
нет `default_factory`, а у класса есть, и сам запрос становится значением, которое можно построить,
изменить и отправить. Подробности — {doc}`Запросы </guides/requests/index>` и {doc}`Запрос как
значение </guides/requests/values>`.

| Было | Стало | Причина |
|---|---|---|
| `def op(self, **request: Unpack[Req]) -> T` | класс `Op(HttpOperation[T])` + `op(Op)` | defaults и `default_factory`, запрос как значение |
| `responses=Responses(…)` | `success=…`, `errors=…`, `fallback=…` | один способ вместо трёх |
| `response=Json()` | return-аннотация операции либо `success={200: Model}` | семья выводится из модели |
| `Annotated[int, Query()]` | `Query[int]` или `Annotated[int, markers.Query("name")]` | короткая форма |
| `eazy_sdk.Path` (дата-класс) | `eazy_sdk.request.markers.Path` | корневые имена стали алиасами |
| `eazy_sdk.request.Query` (дата-класс) | `eazy_sdk.request.markers.Query` | то же для остальных маркеров |
| `Inject(JsonField("x"), dep)` | `Inject(markers.JsonField("x"), dep)` | то же |
| `Wire(projection=…)` | `projection=BodyProjection(target=…, using=…, encoding=…)` в `__http__` | проекция — представление, не байтовый контракт |
| `BodyProjection(source=TypedDict, ...)` | `source` опускается: источник — класс операции | одно объявление полей |
| `eazy_sdk.Responses` | `eazy_sdk.response.Responses` | бюджет корня; вместе с `Success` и `Error` |
| `eazy_sdk.Text` | `eazy_sdk.response.Text` | вместе с `Bytes` |
| `Error(404, Json(Problem), exception=NotFound)` | `errors={404: NotFound}` при `class NotFound(ApiError[Model])` | модель объявлена один раз |
| `Error(..., exception=factory)` | `errors={404: (Model, factory)}` | без наследования от библиотеки |
| `eazy_sdk.response.JsonResponse` | `eazy_sdk.response.Json` | одно имя для одного понятия |
| `eazy_sdk.serialization.Serialization.html` | `eazy_sdk.serialization.Serialization.documents` | несколько документных бэкендов, выбор по медиа |
| `eazy_sdk.websocket.WsOperationKind` | `eazy_sdk.websocket._messages.WsOperationKind` | плумбинг рантайма ушёл из публичной поверхности |
| `eazy_sdk.websocket.RuntimeComposition` | `eazy_sdk.websocket.composition.RuntimeComposition` | то же |
| `eazy_sdk.websocket.FrameLimits` | `eazy_sdk.websocket.frames.FrameLimits` | то же, вместе с `frame_from_zapros`/`frame_to_zapros` |
| `eazy_sdk.response.HtmlExtractor` | `eazy_sdk.response.cases.HtmlExtractor` | вместе с `JsonExtractor` |
| `eazy_sdk.request.TransportProtocol` | `eazy_sdk.request.wire.TransportProtocol` | читает компилятор, не автор SDK |
| `eazy_sdk.crypto.ResolvedCrypto` | `eazy_sdk.crypto.core.ResolvedCrypto` | результат компиляции, не объявление |
| `@ws.call("event") async def f(self, *, ...)` | по-прежнему работает; альтернатива — `class F(WsCall[T])` + `op(F)` | классы и для WebSocket |
| `ApiError.context` после pickle | `ApiError.summary` (`ErrorSummary`) | сводка вместо тела ответа и заголовков |

Новое без замены: `Omittable[T] = UNSET` — единственный способ не отправить поле; `unwrap = "/data"`
на сервисе — конверт снимается один раз; `ClientConfig(errors={host: {...}})` — ошибки, которыми
хост отвечает любому SDK; `RpcOperation`/`Rpc` в `eazy_sdk.protocols` и `WsCall`/`WsSubscribe`/
`WsSend`/`Ws` в `eazy_sdk.websocket` — те же классы для других протоколов;
`eazy-sdk-adaptix` — центральный `Retort` как адаптер моделей.
