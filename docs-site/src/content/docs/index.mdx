Что вы хотите сделать?

Eazy SDK отделяет контракт API от транспорта. Выберите путь по своей текущей задаче.

::::{grid} 1 1 2 2
:gutter: 2
:::{grid-item-card} Начать с нуля
:link: /start/index
:link-type: doc

Установите библиотеку и выполните первый запрос.
:::
:::{grid-item-card} Пройти цельный пример
:link: /tutorial/index
:link-type: doc

Соберите почтовый SDK с входом, сессией, пагинацией, подписью и шифрованием.
:::
:::{grid-item-card} Решить конкретную задачу
:link: /guide/index
:link-type: doc

Найдите практическое руководство по запросам, ответам, авторизации и надёжности.
:::
:::{grid-item-card} Подключить интеграцию
:link: /integrations/index
:link-type: doc

Выберите HTTP-клиент и библиотеку моделей, подключите браузер, сгенерируйте пакет или сохраните
аккаунты в базе данных.
:::
