HTTP-клиент отвечает только за отправку подготовленного запроса. Операции, модели, авторизация,
повторы и разбор ответа остаются общими для всех вариантов.

| Вариант | Режим | Когда выбирать |
|---|---|---|
| HTTPX | синхронный и асинхронный | Обычный SDK без требований к браузерному TLS-отпечатку |
| Requests | синхронный | Проект уже владеет `requests.Session` |
| curl_cffi | синхронный и асинхронный | Сайт проверяет TLS-отпечаток или ожидает браузерное соединение |
| Свой обработчик | зависит от реализации | Нужен другой транспорт или корпоративная сетевая библиотека |

Короткие фабрики `Client.httpx(...)`, `Client.requests(...)` и `Client.curl_cffi(...)` создают
адаптер и закрывают созданный ими сетевой клиент вместе с Eazy SDK. Если передать готовый
`client=` или `session=`, сетевым объектом продолжает владеть вызывающий код.

:::{note}
Повторы и переходы по перенаправлениям выполняет Eazy SDK. Не включайте эти механизмы повторно
в сетевом клиенте: новая попытка должна заново подготовить, зашифровать и подписать запрос.
:::
