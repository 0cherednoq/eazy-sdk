Requests поддерживает только синхронный `Client`. Для готовой сессии используйте
`Client.requests(base_url=..., session=session)`. Eazy SDK не закроет переданную сессию;
закройте её там, где она была создана.

Адаптер отключает автоматические перенаправления, но Requests управляет частью служебных
заголовков. Он не поддерживает повторяющиеся заголовки запроса и потоковое тело. Операция с
такими требованиями завершится ошибкой до отправки, если её профиль требует точной поддержки.

:::{note}
Если API чувствителен к порядку заголовков, их регистру или TLS-отпечатку, выберите HTTPX либо
`curl_cffi` после проверки нужного уровня в профиле обработчика.
:::
