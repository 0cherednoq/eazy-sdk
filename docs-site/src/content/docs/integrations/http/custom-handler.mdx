Метод `handle(...)` не должен сам повторять запрос, переходить по `Location`, менять cookies или
перекодировать готовое тело. Эти решения принимает исполнитель Eazy SDK. Асинхронный вариант
реализует `AsyncBaseHandler.ahandle(...)` и передаётся в `AsyncClient`.

Если обработчик владеет сетевым ресурсом, реализуйте `close()` либо `aclose()`. По умолчанию
клиент вызывает его при закрытии. Для внешнего ресурса передайте `owns_handler=False` и закройте
ресурс на уровне владельца.

Без собственного `HandlerProfile` обработчик получает консервативный профиль. Объявляйте более
сильные возможности только после проверки фактических байтов и поведения транспорта.

:::{warning}
Обработчик является последней границей перед сетью. Не записывайте секретные заголовки или
открытое тело запроса в журнал диагностики.
:::
