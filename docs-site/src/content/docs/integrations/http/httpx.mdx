```bash
uv add "eazy-sdk-core[httpx]"
```

Обе фабрики создают HTTPX-клиент без автоматических перенаправлений. Контекстный менеджер
закрывает пул соединений. `AsyncClient.httpx(...)` принимает параметры конструктора
`httpx.AsyncClient`, а `Client.httpx(...)` параметры `httpx.Client`.

Чтобы использовать существующий пул, передайте `client=`. Eazy SDK не закроет переданный
HTTPX-клиент. Параметр `proxy=` при этом только объявляет уже настроенный прокси в профиле
обработчика; он не меняет конфигурацию чужого объекта.

HTTPX сохраняет повторяющиеся заголовки и готовые байты тела. Точный уровень возможностей
зафиксирован в `HTTPX_HANDLER_PROFILE` и зависит от проверенной версии HTTPX.
