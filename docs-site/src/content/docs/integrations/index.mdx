Используйте эту карту, чтобы установить только нужные зависимости. Каждая интеграция сохраняет
общие контракты операций, авторизации, повторов и ошибок Eazy SDK.

| Пакет | Задача | Страница |

| `eazy-sdk-browser` | Выполнять операции через браузер | {doc}`Браузер </integrations/browser/index>` |

| `eazy-sdk-presets` | Подключить готовые защиты | {doc}`Cloudflare </integrations/protection/cloudflare>`, {doc}`Turnstile </integrations/protection/turnstile>`, {doc}`reCAPTCHA </integrations/protection/recaptcha>` |
