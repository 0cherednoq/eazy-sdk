Используйте эту карту, чтобы установить только нужные зависимости. Каждая интеграция сохраняет
общие контракты операций, авторизации, повторов и ошибок Eazy SDK.

## Дополнения пакета

Все интеграции входят в пакет `eazy-sdk-core`. Дополнение ставит сторонние библиотеки, которые
нужны интеграции. Команда установки выглядит так: `uv add "eazy-sdk-core[httpx,pydantic]"`.

| `curl-cffi` | Имитировать профиль браузера | {doc}`Подключение </integrations/http/curl-cffi>` |
