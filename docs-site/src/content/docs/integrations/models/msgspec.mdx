Установите extra `msgspec`:

```bash
uv add "eazy-sdk-core[msgspec]"
```

`rename` задаёт имя поля в данных API, не меняя имя атрибута Python:

Адаптер читает `rename` класса и `msgspec.field(name=...)`. `frozen=True` сообщает SDK, что
модель нельзя изменить при эволюции подписанного или спроецированного значения.
