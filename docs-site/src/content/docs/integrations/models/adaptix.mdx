`adaptix_models(...)` заменяет штатный адаптер dataclass одним маршрутизатором. Указанные в
`types=` классы проходят через `Retort`; остальные dataclass продолжает обрабатывать встроенная
реализация. Так в реестре не появляются два адаптера для одного типа.

Таблица `names=` нужна компилятору до первого значения модели. Она должна совпадать с
`name_mapping` в рецепте `Retort`.
