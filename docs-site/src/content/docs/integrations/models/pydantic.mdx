Нужна проверка моделей средствами Pydantic?

Установите extra `pydantic`:

```bash
uv add "eazy-sdk-core[pydantic]"
```

Адаптер использует Pydantic v2 для разбора ответа. Alias связывает имя Python с полем API:

```{literalinclude} ../../../../../../examples/docs/integration_pydantic_model.py
:language: python
:start-after: "# docs:integration-pydantic-model:start"
:end-before: "# docs:integration-pydantic-model:end"
```

```{literalinclude} ../../../../../../examples/docs/integration_pydantic_model.py
:language: python
```
:::

<!-- example-output: examples.docs.integration_pydantic_model -->
```text
pydantic: 42 План на пятницу
```

Для входящих данных адаптер учитывает `validation_alias`. При сериализации тела запроса он
использует `serialization_alias` или `alias` согласно конфигурации модели. Ошибка в типах ответа
сохраняет структурированные сведения Pydantic в контексте ошибки SDK.
