кода состояния недостаточно.

```text

```

Перед использованием привяжите решатель, который возвращает `CloudflareClearance`. Исполнитель
проверит cookies, применит их одной закрытой группой и безопасно повторит запрос. Повторная
подтверждённая проверка отменяет прежнее разрешение перед новым решением.

Пресет сам не запускает браузер. Если решателю и HTTP-клиенту нужен общий сетевой путь, создайте
их из одной фиксированной сессии. При смене прокси или профиля имитации создайте новый клиент.
