
`operation(...)` ограничивает политику одной операцией SDK. Решатель возвращает типизированный
токен и не изменяет запрос или состояние повторов. Способ применения, например
`form_field("g-recaptcha-response")`, добавляет закрытое поле перед кодированием и подписью.

Если описание не содержит решателя, привяжите его через механизм внедрения зависимостей до
выполнения запроса. Иначе предварительная проверка конфигурации вернёт типизированную ошибку.
