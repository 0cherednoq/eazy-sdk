Установите отдельный плагин:

```bash
uv add "eazy-sdk-core[xml]"
```

Один `ElementTreeXmlCodec` сериализует модель запроса и разбирает примитивы ответа:

```text
xml order: 42
```

`XmlBody` задаёт `Content-Type: application/xml` и кодирует тело. `XmlResponse` читает XML в
примитивное дерево, после чего общий реестр моделей создаёт `OrderResult`. Ошибка синтаксиса XML
становится ошибкой разбора ответа.

Для извлечения отдельных полей из XML-документа используйте `ElementTreeBackend` и XPath. Этот
бэкенд не поддерживает CSS; несовместимый селектор отвергается при компиляции операции.
