```bash
uv add eazy-sdk-xml
```

Подключите XML codec к request marker и response extractor. Операция остаётся обычным методом
API-класса.

```python
from dataclasses import dataclass
from typing import Annotated

from eazy_sdk import Http, HttpOperation, SyncApi, op
from eazy_sdk.response import Extracted
from eazy_sdk_xml import ElementTreeXmlCodec, XmlBody, XmlResponse

codec = ElementTreeXmlCodec(root_name="order")

@dataclass(frozen=True, slots=True, kw_only=True)
class CreateOrder(HttpOperation[OrderResult]):
    __http__ = Http.post(
        "/orders",
        operation_id="createOrder",
        success={
            201: Extracted(OrderResult, using=XmlResponse(codec), media_type="application/xml")
        },
    )

    order: Annotated[Order, XmlBody(codec=codec)]

class OrdersApi(SyncApi):
    create_order = op(CreateOrder)
```

Пример request: `POST /orders`, `Content-Type: application/xml`, body
`<order><id>42</id></order>`. Пример response: status `201`, `Content-Type: application/xml`, body
`<result><accepted>true</accepted></result>`.

Собственный codec реализует `serialize(value) -> bytes` и `parse(body) -> object`. Он должен быть
детерминированным, если body участвует в signing. `XmlResponse` возвращает primitive tree, после
чего общий `ModelAdapterRegistry` строит dataclass, Pydantic или msgspec model. Malformed XML
становится response parsing error, а не частично заполненной моделью.
