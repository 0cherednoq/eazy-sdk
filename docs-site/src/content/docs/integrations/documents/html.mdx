Установите HTML extra:

```bash
uv add "eazy-sdk[html]"
```

`CSS(...)` связывает поле модели с селектором документа. Операция остаётся обычным HTTP GET:

```{literalinclude} ../../../../../../examples/docs/integration_html_document.py

:end-before: "# docs:integration-html-document:end"
```

<!-- example-output: examples.docs.integration_html_document -->
```text
html: Входящие — План на пятницу
```

`ParselBackend` поддерживает CSS и XPath для `text/html` и `application/xhtml+xml`. `Scope(...)`
задаёт повторяющийся узел для списка вложенных моделей. Отсутствие обязательного поля считается
ошибкой разбора, а optional-поле получает `None`.

:::{note}
Документная модель должна иметь хотя бы одно обязательное поле. Иначе она совпадёт с любой HTML-
страницей, включая страницу ошибки другого ответа.
:::
