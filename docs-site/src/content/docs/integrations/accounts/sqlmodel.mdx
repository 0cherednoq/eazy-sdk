Установите плагин и асинхронный драйвер выбранной базы. Для SQLite:

```bash
uv add eazy-sdk-sqlmodel aiosqlite
```

В примере используется временная SQLite. Для постоянной базы сначала вызовите
`create_all(engine)`. Учётные данные, профиль и данные сессии сохраняются как JSON, поэтому
защиту данных на диске должно обеспечить приложение.

`create_all(...)` предназначен для новой базы. Для обновления старой схемы сначала запустите
`eazy-sdk-sqlmodel-migrate DATABASE_URL` без `--apply`, изучите отчёт, затем повторите команду с
`--apply`.
