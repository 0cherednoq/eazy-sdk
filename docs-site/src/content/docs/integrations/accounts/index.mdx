Пакет `eazy_sdk_accounts` хранит аккаунты, подтверждения, ограничения, связи, события и сессии.
Он не зависит от HTTP-клиента и подходит для нескольких созданных SDK.

Установите хранилище в памяти:

```bash
uv add "eazy-sdk-core[accounts]"
```

Создайте аккаунт, отметьте адрес подтверждённым и выберите подходящую запись из пула:

```{literalinclude} ../../../../../../examples/docs/integration_accounts.py
:language: python
:start-after: "# docs:integration-accounts:start"
:end-before: "# docs:integration-accounts:end"
```

`MemoryStorage` хранит состояние только в текущем процессе. Для SQLite или PostgreSQL используйте
плагин SQLModel.
