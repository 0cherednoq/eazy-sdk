Продолжите `PendingRegistration`, который вернул поток регистрации. Метод `verify(...)` передаёт
доказательство сервису и сохраняет новое состояние аккаунта.

```{literalinclude} ../../../../../../examples/docs/integration_verification.py
:language: python
:start-after: "# docs:integration-verification:start"
:end-before: "# docs:integration-verification:end"
```

:::{dropdown} Файл целиком
```{literalinclude} ../../../../../../examples/docs/integration_verification.py
:language: python
```
:::

<!-- example-output: examples.docs.integration_verification -->
```text
verification: CompleteRegistration
resume: CompleteRegistration
```

После перезапуска `resume(identifier)` читает сохранённое состояние. Принятое доказательство
возвращает завершённую регистрацию; неверное доказательство оставляет её ожидающей подтверждения.
