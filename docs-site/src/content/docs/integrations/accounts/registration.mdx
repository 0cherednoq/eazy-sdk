`account_registration(...)` объединяет сервис удалённой регистрации и локальное хранилище.
Поле с `AccountIdentifier()` становится ключом для возобновления процесса.

Создайте поток и передайте черновик аккаунта:

```{literalinclude} ../../../../../../examples/docs/integration_registration.py
:language: python
:start-after: "# docs:integration-registration:start"
:end-before: "# docs:integration-registration:end"
```

:::{dropdown} Файл целиком
```{literalinclude} ../../../../../../examples/docs/integration_registration.py
:language: python
```
:::

<!-- example-output: examples.docs.integration_registration -->
```text
registration: PendingRegistration
remote id: user-42
```

Сервис примера вернул `VerificationChallenge`, поэтому поток сохранил аккаунт и вернул
`PendingRegistration`. Если подтверждение не требуется, результатом будет `CompleteRegistration`.
Кодек хранилища отвечает за сериализацию учётных данных; не записывайте секреты в журналы.
