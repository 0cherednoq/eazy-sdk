`eazy_sdk_browser` отделяет сценарий сайта от конкретного браузера. Операция объявляет переход,
элементы и наблюдаемые исходы. `AsyncBrowserClient` выполняет её через драйвер одной страницы.

## Сравнить возможности

| Возможность | Playwright | Pydoll 3 |
|---|---|---|
| Наблюдение за ответами сети | подтверждено захватом | подтверждено захватом |
| Cookies и localStorage | подтверждено захватом | частичная поддержка |
| Запрос из контекста страницы | подтверждено захватом | подтверждено захватом |
| События перехода | подтверждено захватом | подтверждено захватом |
| Shadow DOM через обычный локатор | подтверждено захватом | не поддерживается |
| HTML в редакторе | подтверждено захватом | подтверждено захватом |

Таблица повторяет `PLAYWRIGHT_PROFILE` и `PYDOLL_PROFILE`. Если создать драйвер с
`capture=None`, оба профиля объявят наблюдение за сетью неподдерживаемым. Остальные возможности
не меняются.

Playwright удобен для нового проекта и полноценно работает с состоянием контекста. Pydoll нужен,
когда приложение уже управляет Chromium через Pydoll 3 или передаёт вкладки из пула. Операции и
роутеры при смене драйвера не меняются.

:::{note}
Профиль описывает проверенную границу адаптера, а не все функции браузерной библиотеки. Доступ к
нативной `Page` или `Tab` остаётся у драйвера для действий вне декларативного контракта.
:::
