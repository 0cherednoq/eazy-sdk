Установите extra `pydoll`:

```bash
uv add "eazy-sdk-core[browser,pydoll]"
```

Адаптер поддерживает `pydoll-python>=3,<4`. Он принимает готовую `Tab` и не запускает браузер
самостоятельно:

```{literalinclude} ../../../../../../examples/docs/integration_pydoll.py
:language: python
:start-after: "# docs:integration-pydoll:start"
:end-before: "# docs:integration-pydoll:end"
```

```text

```

Закрытие `PydollDriver` снимает только его CDP callbacks и освобождает внутренний буфер ответов.
Вкладку и браузер закрывает создавший их код. Для нескольких вкладок одного контекста передайте
им одинаковый `context_key`; без него каждый драйвер считается отдельным контекстом.

Pydoll выгружает cookies контекста и localStorage текущего origin на уровне `BEST_EFFORT`.
Shadow DOM через обычный локатор не поддерживается. Операция, которая явно требует
`Capability.shadow_dom`, будет отвергнута до выполнения.
