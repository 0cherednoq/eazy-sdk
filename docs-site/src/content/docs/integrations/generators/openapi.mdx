Генератор OpenAPI превращает операции, схемы и параметры документа в готовый пакет Python.
Установите отдельный пакет генератора:

```bash
uv add "eazy-sdk-openapi[yaml]"
```

Передайте разобранный документ, путь исходной спецификации и каталог результата:

```{literalinclude} ../../../../../../examples/docs/integration_openapi.py
:language: python
:start-after: "# docs:integration-openapi:start"
:end-before: "# docs:integration-openapi:end"
```

:::{dropdown} Файл целиком
```{literalinclude} ../../../../../../examples/docs/integration_openapi.py
:language: python
```
:::

<!-- example-output: examples.docs.integration_openapi -->
```text
package: mail_sdk
files: __init__.py, _model_base.py, auth.py, client.py, dependencies.py, models.py, openapi-compatibility.json, py.typed, signatures.py
```

Файл `openapi-compatibility.json` перечисляет упрощённые элементы спецификации и места, которые
требуют ручной настройки. Генерация из JSON не требует extra `yaml`.

Для командной строки передайте файл, каталог и имя пакета:

```bash
eazy-sdk-openapi openapi.yaml generated --package-name mail_sdk
```
