## Mandatory operation flow

```python
requirement = ProtectionRequirement[Result]("login-protection")
flow = protection_flow(
    requirement,
    acquire=ProtectionApi.acquire,
    solve=True,
    verify=ProtectionApi.verify,
)
solvers = SolverBindings(bind_solver(requirement, solver))
```

`ProtectionFlow` имеет три формы: acquire-only, acquire + solve и acquire + solve + verify.
`FromProtection(requirement, field)` рекурсивно связывает typed result с точным полем private target
модели `BodyProjection`. Все managed fields одного result применяются атомарно на каждой HTTP
attempt после projection и до финальной target-валидации.

Operation объявляет `protections=(requirement,)`; `ClientConfig` получает `protections=(flow,)` и
`protection_solvers=solvers`. Missing flow, solver или field mapping завершается до сети.

## Conditional and domain policies

Conditional challenge остаётся response case/reaction. External WAF policy имеет reusable scope и
также подключается через `ClientConfig.protections`.

    scope=...,

Presets возвращают scoped client policies. Captcha-specific names принадлежат конкретным vendor
models; общая operation abstraction называется Protection.
