Наследуйте `AsyncApi` или `SyncApi` и объявляйте HTTP-операции через узкий namespace `api`.
Python-сигнатура метода становится публичной сигнатурой SDK. Тело метода не выполняется.

```python
from typing import Annotated, NotRequired, TypedDict, Unpack

from pydantic import BaseModel

from eazy_sdk import SyncApi, api
from eazy_sdk.clients import CallOptions
from eazy_sdk.request import Path, Query
from eazy_sdk.response import Json, Responses, Success

class User(BaseModel):
    id: int
    name: str

USER_RESPONSES = Responses[User](success=(Success(200, Json(User)),))

class GetUserRequest(TypedDict):
    user_id: Annotated[int, Path()]
    include: NotRequired[Annotated[str, Query()]]

class UsersApi(SyncApi):
    @api.get("/users/{user_id}", operation_id="getUser", responses=USER_RESPONSES)
    def get_user(
        self,
        *,
        options: CallOptions | None = None,
        **request: Unpack[GetUserRequest],
    ):
        raise NotImplementedError
```

Тип `User` выводится из `Responses[User]`; дублировать его в return-аннотации пустой декларации не
нужно. Обычный вызов возвращает `User`. Вызов `get_user.with_response(...)` возвращает
`ResponseEnvelope[User, Any]` с распарсенным значением, status, headers и transport response.

## Namespace `api`

Используйте один импорт:

```python
from eazy_sdk import api
```

У объекта `api` ровно пять публичных атрибутов:

- `api.get`
- `api.post`
- `api.put`
- `api.patch`
- `api.delete`

`SyncApi`, `AsyncApi`, runtime-типы и ad-hoc методы клиента в `api` не входят. Отдельные top-level
verb imports не поддерживаются. Декораторов `head`, `options` и `trace` в текущем декларативном
API нет.

## Параметры HTTP-декоратора

Все пять декораторов имеют одну сигнатуру.

| Параметр | Назначение | Default |
|---|---|---|
| `path` | URL path с `{placeholder}` | обязательный |
| `responses` | `Responses` с success/error/fallback cases | обязательный |
| `operation_id` | Стабильная identity операции | имя функции |
| `security` | Схема или policy авторизации | inherited |
| `requires` | Typed dependencies операции | `()` |
| `inject` | Request-owned значения, объявленные через `Inject` | `()` |
| `signing` | Одна или несколько request signatures | inherited |
| `crypto` | `PayloadCrypto` для request/response payload | inherited |
| `crypto_wire` | Wire policy для encoded crypto | inherited |
| `protections` | Обязательные `ProtectionRequirement` | `()` |
| `body` | `BodyProjection` из public kwargs в private wire schema | `None` |
| `wire` | `WireOptions` для порядка и exact protocol | `None` |
| `tags` | Metadata для группировки и генерации | `()` |
| `idempotent` | Явное доказательство безопасного replay | выводится из HTTP method |
| `raw_response` | Вернуть normalized raw response | `False` |

## Наследуемые defaults

`ApiDefaults` содержит четыре поля: `security`, `signing`, `crypto` и `crypto_wire`.

```python
from eazy_sdk import ApiDefaults, AsyncApi

class PaymentsApi(AsyncApi):
    defaults = ApiDefaults(
        security=PAYMENT_AUTH,
        signing=(PAYMENT_SIGNATURE,),
        crypto=PAYMENT_CRYPTO,
        crypto_wire=PAYMENT_WIRE,
    )
```

Если аргумент декоратора не указан, операция наследует соответствующий default. Явное `None`
отключает наследование для одной операции. Для `signing` пустой tuple также означает отсутствие
подписей.

## Правила сигнатуры метода

- `AsyncApi` принимает только `async def`, `SyncApi` только `def`.
- Первый параметр должен быть instance parameter (обычно `self`).
- Каждая operation с HTTP input объявляет один именованный `TypedDict`. Обычные поля имеют ровно
  один placement marker; поля `BodyProjection.source` намеренно остаются unplaced.
- `options`, если он нужен, объявляется как keyword-only `CallOptions | None = None`.
- `Responses[T]` задаёт тип успешного результата; return-аннотация пустой декларации необязательна.
- Path placeholders должны точно совпадать с полями `Annotated[..., Path()]` request-`TypedDict`.
- `operation_id` должен быть уникальным внутри API-класса.
- Прямые HTTP-параметры в сигнатуре не используются. Раскрывайте request только как
  `**request: Unpack[TypedDict]`; `CallOptions` является единственным отдельным control argument.

Ошибки декларации обнаруживаются при создании API-класса, до создания клиента и сетевого вызова.

> **Примечание:** `mypy --strict` отдельно запрещает любую функцию без return-аннотации кодом
> `no-untyped-def`. Для модулей, содержащих только декларации API, отключите этот код через
> `# mypy: disable-error-code="no-untyped-def"`. Тип вызова при этом остаётся `T` из
> `Responses[T]`.
