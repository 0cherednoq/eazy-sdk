Наследуйте `AsyncApi` или `SyncApi`. Сигнатура метода становится публичной сигнатурой SDK,
а тело декларации не выполняется.

## Явные keyword-only параметры

Этот стиль удобен для hand-written SDK: Python defaults видны IDE и передаются в
`BodyProjection` как обычные значения.

```python
from typing import Annotated

from pydantic import BaseModel
from eazy_sdk import AsyncApi, api
from eazy_sdk.request import Path, Query
from eazy_sdk.response import Json

class User(BaseModel):
    id: int

class UsersApi(AsyncApi):
    @api.get("/users/{user_id}", response=Json())
    async def get_user(
        self,
        *,
        user_id: Annotated[int, Path()],
        include: Annotated[str | None, Query()] = None,
        page: Annotated[int, Query()] = 1,
    ) -> User:
        raise NotImplementedError
```

HTTP-параметры всегда keyword-only. Для запроса разрешён либо этот стиль, либо
`**request: Unpack[TypedDict]`; смешивать их в одной операции нельзя. Единственное исключение —
служебный `options: CallOptions | None = None`.

## `Unpack[TypedDict]`

Reusable и generated SDK могут сохранить именованную схему:

```python
from typing import Annotated, NotRequired, TypedDict, Unpack

from pydantic import BaseModel
from eazy_sdk import AsyncApi, api
from eazy_sdk.request import Path, Query
from eazy_sdk.response import Json

class User(BaseModel):
    id: int

class GetUserRequest(TypedDict):
    user_id: Annotated[int, Path()]
    include: NotRequired[Annotated[str, Query()]]

class GeneratedUsersApi(AsyncApi):
    @api.get("/users/{user_id}", response=Json())
    async def get_user(self, **request: Unpack[GetUserRequest]) -> User:
        raise NotImplementedError
```

Оба стиля lower-ятся в один `MethodInputSchema` и один executor. Positional HTTP arguments не
поддерживаются.

## Ответ операции

Для одной успешной case используйте `response=`. Модель берётся из обязательной return-аннотации:

```python
from typing import Annotated

from pydantic import BaseModel
from eazy_sdk import AsyncApi, api
from eazy_sdk.request import Path
from eazy_sdk.response import Error, Json

class User(BaseModel):
    id: int

class NotFound(BaseModel):
    detail: str

class UserNotFound(Exception):
    pass

COMMON_ERRORS = ()

class UsersApi(AsyncApi):
    errors = COMMON_ERRORS

    @api.get(
        "/users/{user_id}",
        response=Json(status=200),
        errors=(Error(404, Json(NotFound), exception=UserNotFound),),
    )
    async def get_user(self, *, user_id: Annotated[int, Path()]) -> User:
        raise NotImplementedError
```

Operation errors добавляются после `errors`, объявленных на классе роутера. Передайте `inherit_errors=False`, чтобы
отключить inherited cases. `response=` и `responses=` взаимоисключающие. Используйте полный
`Responses[T]` для нескольких success cases, fallback и сложной arbitration.

## Namespace `api`

Стандартные decorators:

- `api.get`, `api.post`, `api.put`, `api.patch`, `api.delete`;
- `api.head`, `api.options`, `api.trace`.

Для другого валидного HTTP token используйте единый generic entry point:

```python
from pydantic import BaseModel
from eazy_sdk import AsyncApi, api
from eazy_sdk.response import Json

class Resources(BaseModel):
    items: list[str]

class ResourceApi(AsyncApi):
    @api.request("PROPFIND", "/resources", response=Json())
    async def resources(self) -> Resources:
        raise NotImplementedError
```

Все helpers делегируют одному operation compiler. Невалидный token отклоняется при создании
decorator.

## Параметры decorator

| Параметр | Назначение | Default |
|---|---|---|
| `path` | URL path с `{placeholder}` | обязательный |
| `response` | Одна success representation | — |
| `responses` | Полный `Responses` contract | — |
| `errors` | Локальные typed error cases | `()` |
| `inherit_errors` | Добавить `errors` роутера | `True` |
| `operation_id` | Стабильная identity операции | имя метода |
| `security` | Auth scheme или policy | inherited |
| `requires`, `inject` | Managed request dependencies | `()` |
| `signing` | Request signatures | inherited |
| `crypto`, `crypto_wire` | Payload crypto и wire policy | inherited |
| `protections` | Mandatory protection requirements | `()` |
| `body` | `BodyProjection` | `None` |
| `wire` | `WireOptions` | `None` |
| `tags` | Metadata | `()` |
| `idempotent` | Явное replay-доказательство | выводится из method |
| `raw_response` | Вернуть normalized response | `False` |

Роутер объявляет `base_url`, `security`, `signing`, `crypto`, `crypto_wire`, `errors` и `allow`
обычными атрибутами класса; они наследуются по MRO, поэтому общий для нескольких роутеров
сервис описывается обычным базовым классом (см. {doc}`Мультисервисный SDK </guides/multi-service>`).

## Подготовка без отправки

Bound operation поддерживает ту же sync/async форму через `.prepare(...)`:

```python
prepared = await users.get_user.prepare(
    user_id=42,
    options=PrepareOptions(resolve_managed=False),
)
```

`prepare` выполняет обычные bind/default/project/encode/sign стадии и останавливается на общей
границе перед handler send. Pure mode не вызывает providers и возвращает
`PreparationIncompleteError`, если нужны managed values. Full mode (`resolve_managed=True`) использует
test providers, но сеть всё равно не вызывается. `PreparedCall` редактирует secret headers,
cookies, query и private body.

Сохраняйте `raise NotImplementedError` как недостижимое тело обычной strict-mypy декларации.
`...` приводит к `empty-body` ошибке type checker.
