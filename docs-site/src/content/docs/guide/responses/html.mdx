Поля документной модели несут CSS- или XPath-селекторы. SDK сначала строит дерево HTML, затем
извлекает простые значения и передаёт их настроенному адаптеру моделей.

Модель остаётся обычным `dataclass`.

**← Response** · ``200 OK``
```html
<h1>Mailbox library</h1>
<article class="book">
  <a href="sdk-patterns.html">SDK Patterns</a><span>12.50</span>
</article>
```

`CSS("a::text")` читает текст одного узла. `Scope(CSS("article.book"))` создаёт отдельный
контекст для каждой карточки и строит список `Book`. Необязательное поле получает `None`, если
селектор ничего не нашёл; обязательное поле приводит к `ExtractionError` с путём модели.

Селекторы в `Catalogue` сообщают компилятору, что ответ нужно читать как документ. Модель без
селекторов на том же месте читалась бы как JSON. Явное представление `Html(Model)` нужно для
особого статуса, типа содержимого или условия.


По умолчанию HTML читает Parsel с поддержкой CSS и XPath. Другой документный бэкенд задаётся в
`Serialization(documents=(...))` на корне. Компилятор заранее проверяет, что бэкенд понимает язык
каждого селектора.
Для отдельного HTML-фрагмента без HTTP используйте `parse_html(data, Model)`. Он применяет ту же
модель, селекторы и адаптеры.
