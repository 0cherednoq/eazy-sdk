## Выбрать hook попытки

| Hook | Допустимый результат |
|---|---|
| `contribute(context)` | `ValuePatch` до подготовки запроса |
| `before_emit(context)` | `Continue`, `Fail` или `None` |
| `after_response(context)` | `Continue`, `ReplaceResponse`, `ProposeAction` или `Fail` |
| `on_transport_error(context)` | `Continue`, `ProposeAction` или `Fail` |

Глобальные middleware задаются через `ClientConfig(hooks=Hooks(...))`. Для одного вызова укажите
регистрацию в `CallOptions` метода `send(...)`; остальная конфигурация клиента останется прежней.

Captcha оформляется guard, а обновление токена управляемой сессией. Middleware не должно
создавать для них второй путь выполнения.
