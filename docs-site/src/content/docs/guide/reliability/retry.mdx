Каждая попытка заново разрешает зависимости с политикой `ATTEMPT`, строит wire-представление,
шифрует и подписывает байты. Одноразовый stream можно повторить только через
`ReplayableStreamBody`. Для безопасного POST операция должна явно объявить `idempotent=True`.

| Бюджет | Что ограничивает |
|---|---|
| `max_attempts` | Все попытки логического вызова |
| `transport_retries` | Повторы после ошибки транспорта |
| `auth_retries` | Повторы после обновления сессии |
| `max_redirects` | Переходы по `Location` |
| `RetryPolicy` | Методы, статусы, задержку и backoff |

Общий timeout и cancellation останавливают ожидание. Protection replay имеет отдельное
доказательство и бюджет, но всё равно расходует обычную попытку отправки.
