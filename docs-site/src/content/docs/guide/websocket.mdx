`WsSend` отправляет сообщение без ответа. `WsCall[T]` ждёт один типизированный ответ, а
`WsSubscribe[T]` возвращает поток событий. Все поля класса входят в payload.

## Выбрать протокол и жизненный цикл

`JsonEventProtocol` подходит для событий с discriminator. `GraphqlTransportWsProtocol` реализует
`graphql-transport-ws`, включая `connection_init`, `connection_ack`, `next`, `error` и `complete`.

| Credential | Когда читается |
|---|---|
| `StaticUpgradeAuth` | При создании Zapros-клиента для HTTP upgrade |
| `ProtocolAuth` | Для каждого нового поколения соединения |
| `DynamicPerMessageAuth` | Перед каждым прикладным сообщением |

Повтор `send` или `call` требует явной политики, потому что доставка после разрыва может быть
неизвестна. Для subscription отдельно задаётся resubscribe, способ восстановления позиции,
ограниченная очередь и policy overflow, чтобы медленный потребитель не накапливал события без
границы.

## Сгенерировать из AsyncAPI

```bash
uv add "eazy-sdk-asyncapi[yaml]"
eazy-sdk-asyncapi asyncapi.yaml generated --package-name market_stream
```

Генератор читает AsyncAPI 3.0 для `ws` и `wss`, создаёт модели, протокол и тонкий `AsyncWsApi`.
Приложение по-прежнему владеет клиентом, reconnect policy и профилями шифрования.
