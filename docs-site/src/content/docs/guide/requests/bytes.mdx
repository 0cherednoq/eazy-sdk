Используйте `BytesBody`, когда приложение уже создало окончательные байты. SDK не применяет к
ним JSON, form или multipart-кодирование.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``PUT /objects/report.bin``
```text
Content-Type: application/octet-stream

mail
```
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``201 Created``
```json
{"stored": true, "bytes": 4}
```
::::
:::::

```{literalinclude} ../../../../../../examples/docs/request_bytes.py
:language: python
:start-after: "# docs:example:start"
:end-before: "# docs:example:end"
```

`payload` передаёт четыре байта без преобразования. `content_type` задаёт заголовок тела. Для
gzip или deflate укажите `content_encoding`: сжатие завершится до вычисления подписи.

:::{dropdown} Файл примера целиком
```{literalinclude} ../../../../../../examples/docs/request_bytes.py
:language: python
```
:::

Запуск: `uv run python examples/docs/request_bytes.py`.

<!-- example-output: examples.docs.request_bytes -->
```text
stored: True; bytes: 4
```

Для потока, который можно отправить повторно, используйте `ReplayableStreamBody`. Обычный
одноразовый поток нельзя безопасно повторить после ошибки транспорта.
