Объявите каждое поле плоского JSON как `JsonField[T]`. Вызов получит точную сигнатуру без
словаря `body`, а SDK проверит обязательные значения до отправки.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``POST /users``
```json
{"name": "Ada", "tags": ["admin"]}
```
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``201 Created``
```json
{"id": 42, "name": "Ada"}
```
::::
:::::

Для `tags` создаётся новый список при каждом вызове. `note=UNSET` не попадает в объект. Явное
`note=None` станет JSON `null`, если аннотация разрешает `None`.

```text

```

Для одного вложенного документа используйте модель с `markers.JsonBody()`. Её адаптер отвечает
за псевдонимы, значения по умолчанию и исключение полей. Не смешивайте корневое тело с
`JsonField` в одной операции. Если публичные поля должны превратиться в другую структуру,
используйте {doc}`BodyProjection </guide/requests/representation>`.
