Используйте `Path[T]`, когда API ждёт значение внутри адреса. Имя поля должно совпадать с
заполнителем в шаблоне пути.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``GET /users/42``
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``200 OK``
```json
{"id": 42, "name": "Ada"}
```
::::
:::::

```{literalinclude} ../../../../../../examples/docs/request_path.py
:language: python
:start-after: "# docs:example:start"
:end-before: "# docs:example:end"
```

Поле `user_id` заполняет `{user_id}` и принимает только `int`. Если Python-имя отличается от
имени в URL, используйте `Annotated[int, markers.Path("id")]`.

:::{dropdown} Файл примера целиком
```{literalinclude} ../../../../../../examples/docs/request_path.py
:language: python
```
:::

Запуск: `uv run python examples/docs/request_path.py`.

<!-- example-output: examples.docs.request_path -->
```text
user: 42 Ada
```

SDK отклоняет объявление, если заполнитель остался без поля, поле `Path` не имеет заполнителя
или одно место описано дважды. Необязательный параметр пути невозможен: адрес должен быть
однозначным до отправки.
