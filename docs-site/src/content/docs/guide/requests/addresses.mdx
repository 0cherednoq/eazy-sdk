У запроса бывает два адреса, которых нет в пути операции. Первый называет соседний сервис: форма
входа уходит на один хост с `Origin` и `Referer` страницы на другом. Второй приходит в ответе:
письмо называет, где лежит вложение.

## Адрес соседнего сервиса

`service_url(PagesApi)` отдаёт адрес, к которому роутер привязан в корне SDK: `bind(PagesApi,
base_url=...)`, собственный `base_url` роутера или адрес клиента. Значение читается при подготовке
запроса, поэтому перенос сервиса на другой хост меняет и заголовки, которые его называют.

Второй аргумент дописывает путь. Без роутера `service_url()` называет сервис самой операции.
Базовый класс называет все роутеры, которые его наследуют, и у них должен быть один адрес.
Роутер, которого нет в корне, останавливает вызов до сети.

## Адрес из ответа

`Http.get(markers.Url(hosts=...))` объявляет операцию без собственного пути. Адрес приходит
аргументом в поле `url: Url[str]`. Запрос несёт куки, которые сайт поставил для этого адреса,
идёт через тот же клиент, с его прокси и таймаутом.

`hosts` обязателен. Ссылка на хост вне списка отклоняется до подготовки запроса: куки, сессия и
подпись сервиса не предназначены для хоста, который сервер только назвал. Относительная ссылка
резолвится против адреса сервиса и в списке не нуждается.

У такой операции нет `Path`-полей. Объявленное `Query`-поле добавляется к ссылке.

## Куки пользователя

`cookies_of(sdk)` отдаёт снимок кук, которые держит пользователь SDK. Его можно сохранить до
следующего запуска и передать в `Identity(cookies=...)`.
