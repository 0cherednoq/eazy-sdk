Используйте `markers.Cookie`, если значение выбирает вызывающий: язык интерфейса, согласие,
параметр из документации API. Куки, которые ставит сам сайт, полями не объявляют: их несёт
библиотека, когда корень объявил `Cookies(...)`. Ключ API, который вызывающий приносит сам и
который сайт ждёт в куке, задаёт `CookieScheme`.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``GET /dashboard``
```text
Cookie: experiment=new-nav
```
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``200 OK``
```json
{"experiment": "new-nav", "widgets": 3}
```
::::
:::::

`experiment` становится cookie с тем же именем. Значение `UNSET` не добавляет cookie. Несколько
объявленных значений SDK объединяет в один корректный заголовок `Cookie`.
