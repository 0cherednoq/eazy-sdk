Используйте `Query[T]` для параметров после `?`. Обычное значение по умолчанию отправляется.
Поле `Omittable[T] = UNSET` исчезает из запроса, пока вызывающий его не передал.

Так URL остаётся коротким.

:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``GET /users?q=ada``
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``200 OK``
```json
[{"id": 42, "name": "Ada", "query": "ada"}]
```

`q` обязателен. `limit` не попадает в URL при значении `UNSET`. Если аннотация допускает `None`,
явное значение `None` кодируется отдельно и не считается пропущенным полем.

```text
query: ada; result: Ada
```

Для другого имени на проводе укажите `markers.Query("page-size")`. Параметры `style`, `explode`
и `allow_reserved` управляют совместимой с OpenAPI сериализацией сложных значений. `Wire`
задаёт порядок параметров и правило кодирования пробелов, если сервер различает эти варианты.
