Объявите запрос неизменяемым классом `HttpOperation[T]`. Поля класса становятся аргументами
вызова, `__http__` хранит HTTP-контракт, а `op(...)` публикует операцию на роутере. Редактор кода
видит сигнатуру до запуска программы.

Это основной вариант.
Он сохраняет отдельный тип запроса, поддерживает фабрики значений по умолчанию и позволяет
переиспользовать общие поля через обычное наследование моделей.

`Order` задаёт тип успешного ответа. `success={201: Order}` связывает статус `201` с этой моделью.
Маркер `JsonField[str]` помещает `item` в JSON-тело. `kw_only=True` делает все аргументы
именованными, поэтому добавление нового поля не меняет смысл старых вызовов.

Декоратор синтезирует такой же неизменяемый класс и публикует его тем же дескриптором. Python не
выполняет тело метода во время вызова SDK. Полученный класс доступен как
`CompactOrdersApi.create.Operation`.

```text

```

| Задача | Класс и `op(...)` | Декоратор |
|---|---|---|
| `default_factory`, наследование полей, проекция | подходит | ограничен сигнатурой метода |
| запрос как отдельное значение | прямой класс операции | синтезированный `.Operation` |
| короткая операция без сложного тела | больше строк | компактнее |
