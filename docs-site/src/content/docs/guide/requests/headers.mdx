Используйте `markers.Header`, когда заголовок относится к одному вызову. Явно задайте имя на
проводе, если оно отличается от Python-поля.

Регистр имени не важен.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``GET /reports``
```text
Accept-Language: ru
```
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``200 OK``
```json
{"locale": "ru", "request_id": null}
```
::::
:::::

```{literalinclude} ../../../../../../examples/docs/request_headers.py
:language: python
:start-after: "# docs:example:start"
:end-before: "# docs:example:end"
```

`locale` всегда отправляется и по умолчанию равен `en`. `request_id` со значением `UNSET` не
создаёт заголовок. SDK сохраняет объявленное написание имени для обработчиков, которые умеют
передавать заголовки без нормализации.

:::{dropdown} Файл примера целиком
```{literalinclude} ../../../../../../examples/docs/request_headers.py
:language: python
```
:::

Запуск: `uv run python examples/docs/request_headers.py`.

<!-- example-output: examples.docs.request_headers -->
```text
locale: ru; request id: None
```

Не передавайте заголовки авторизации, подписи или управляемой защиты как обычные аргументы.
Эти значения принадлежат `Identity` и политикам клиента, которые применяются при подготовке
каждой попытки.
