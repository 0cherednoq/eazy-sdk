Используйте `Form[T]` для входа через HTML-форму и других методов, которые принимают
`application/x-www-form-urlencoded`.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2
::::{grid-item}
:class: http-panel http-panel--request
**→ Request** · ``POST /login``
```text
Content-Type: application/x-www-form-urlencoded

email=ada%40mail.example&password=mail-password
```
::::
::::{grid-item}
:class: http-panel http-panel--response
**← Response** · ``200 OK``
```json
{"account": "ada@mail.example", "access_token": "session-1"}
```
::::
:::::

```{literalinclude} ../../../../../../examples/docs/request_form.py
:language: python
:start-after: "# docs:example:start"
:end-before: "# docs:example:end"
```

`email` и `password` обязательны. `remember=UNSET` не добавляет поле в тело. Для одной модели
целиком используйте `FormBody()` и не смешивайте её с отдельными полями `Form`.
