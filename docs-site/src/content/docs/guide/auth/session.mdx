Передайте `session=`, если приложение уже загрузило сохранённую модель. Runtime проверит срок,
добавит credential в защищённый запрос и не вызовет login без необходимости.

:sync-group: transport

::::{tab-item} HTTP
:sync: http

`session=` для продолжения. Оба значения связываются с одной `USER_SESSION`.

:::::

| Начальное состояние | Действие runtime | Первый HTTP-вызов |
|---|---|---|
| Валидная `session` | Использовать Bearer-поле | Защищённая операция |
| Просроченная `session` | Вызвать `refresh(...)` | Refresh-операция |
| Только `credentials` | Вызвать `acquire(...)` | Login-операция |
| Ни сессии, ни credentials | Остановить планирование | HTTP-вызова нет |

Для сохранения между запусками передайте совместимый `SessionStore` и стабильный `identity` в
настройку схемы. Новая revision записывается только после успешного login или refresh.
