Передайте готовую session, если login уже был выполнен. `UserSession`, `LoginCredentials`,
`AsyncAuthApi` и `LoginService` на этой странице те же, что объявлены в {doc}`Login </auth/login>`.

```python
from eazy_sdk.auth import session_auth

auth = session_auth(
    UserSession,
    session=saved_session,
    service=LoginService(),
)
```

Укажите ровно один аргумент: `credentials=` или `session=`.

Автор hand-written SDK может один раз объявить ту же scheme для API defaults и lifecycle binding:

```python
from dataclasses import dataclass

from eazy_sdk import AsyncApi, AsyncRoot, Http, HttpOperation, Identity, api_group, op
from eazy_sdk.auth import session_scheme
from eazy_sdk.handlers.httpx import AsyncHttpxHandler

USER_SESSION = session_scheme(UserSession, name="user-session")

@dataclass(frozen=True, slots=True, kw_only=True)
class GetAccount(HttpOperation[Account]):
    __http__ = Http.get("/account", operation_id="getAccount")

class AccountApi(AsyncApi):
    security = USER_SESSION

    get_account = op(GetAccount)

class StoreSdk(AsyncRoot):
    auth = api_group(AsyncAuthApi)
    account = api_group(AccountApi)

auth = USER_SESSION.configure(
    credentials=credentials,
    service=LoginService(),
)
async with StoreSdk.from_handler(
    handler=AsyncHttpxHandler(),
    base_url="https://api.example.test",
    identity=Identity(auth=(auth,)),
) as sdk:
    account = await sdk.account.get_account()
```

`session_auth(...)` сохраняет свою короткую форму для SDK без reusable API default. В root SDK
`SessionScheme.configure(...)` создаёт тот же lifecycle binding, а конструктор корня
(`StoreSdk(client)` или `StoreSdk.from_handler(...)`) сам регистрирует фабрику scoped SDK:
`LoginService` получает `context.sdk` типа `StoreSdk` без untyped lambda и без передачи scheme в
каждый экземпляр. Чтобы потребитель передавал только `credentials=`/`session=`, спрячьте
`configure(...)` в override `from_handler`, как показано в {doc}`Login </auth/login>`.

Без `store=` session хранится в памяти процесса. Передайте совместимый store, чтобы сохранить её:

```python
from eazy_sdk.auth import session_auth

auth = session_auth(
    UserSession,
    credentials=credentials,
    service=LoginService(),
    store=session_store,
    identity="ada@example.test",
)
```

После успешного login и refresh новое значение автоматически передаётся в `session_store`.

## SQLModel store

`SqlSessionStore` реализует нейтральный `SessionStore` и может передаваться прямо в
`session_auth(...)`:

```python
from eazy_sdk.auth import session_auth
from eazy_sdk_sqlmodel import SqlSessionStore

session_store = SqlSessionStore(
    database_session,
    account.id,
    session_model=UserSession,
)
auth = session_auth(
    UserSession,
    credentials=credentials,
    service=LoginService(),
    store=session_store,
    identity=account.identifier,
)
```

Используйте отдельный `AsyncSession` для lifecycle store. `SqlSessionStore` атомарно сохраняет
session и lifecycle event, проверяет CAS revision и отклоняет явную внешнюю transaction.

## Что хранит session model

| Аннотация | Назначение |
|---|---|
| `Bearer()` | Поле access token и способ заполнить `Authorization` |
| `RefreshToken()` | Поле, которое service передаст refresh-ручке |
| `ExpiresAt(leeway=...)` | Время, после которого runtime обновит session заранее |

Модель должна содержать ровно одно поле `Bearer`, не более одного `RefreshToken` и не более одного
`ExpiresAt`. Готовая `session=` и `credentials=` взаимоисключающие.
