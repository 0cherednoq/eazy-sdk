HTTP-клиент передаёт JWT как строку с префиксом `Bearer`. Он не декодирует claims и не решает,
можно ли доверять подписи токена.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2

::::{grid-item}
:class: http-panel http-panel--request

**→ Запрос** · ``GET /auth/jwt``

```json
{"headers": {"Authorization": "Bearer eyJhbGciOiJIUzI1NiJ9.demo.signature"}}
```
::::

::::{grid-item}
:class: http-panel http-panel--response

**← Ответ** · ``200 OK``

```json
{"credential": "jwt"}
```

`BearerScheme("mail-jwt")` отвечает только за размещение credential. Проверка `issuer`,
`audience`, срока действия и подписи принадлежит серверу или доверенному компоненту приложения.

Не передавайте JWT в параметре запроса и не выводите его в журнал. Если токен приходит после
login и обновляется по refresh token, храните его в модели управляемой сессии.
