Используйте `BearerScheme`, когда приложение уже получило access token и SDK не должен его
обновлять. Схема добавляет префикс `Bearer` сама.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2

::::{grid-item}
:class: http-panel http-panel--request

**→ Запрос** · ``GET /auth/bearer``

```json
{"headers": {"Authorization": "Bearer access-1"}}
```
::::

::::{grid-item}
:class: http-panel http-panel--response

**← Ответ** · ``200 OK``

```json
{"credential": "access-1"}
```
::::
:::::

```{literalinclude} ../../../../../../examples/docs/auth_bearer.py
:language: python
:start-after: "# region docs: auth-bearer"
:end-before: "# endregion docs: auth-bearer"
```

Операция объявляет `security=ACCESS_TOKEN`, а `Identity` предоставляет значение этой же схемы.
Если источник отсутствует, план вызова завершится до HTTP-запроса.

Для входа и автоматического обновления не заменяйте значение в `Identity` вручную. Используйте
управляемую сессию из разделов про login и refresh.
