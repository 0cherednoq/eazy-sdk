`all_of(...)` объединяет схемы в одно обязательное требование. `any_of(...)` перечисляет
альтернативы и выбирает первую, для которой `Identity` содержит все источники.

```json
{
  "headers": {
    "X-Device-Key": "device-7",
    "Authorization": "Bearer access-1"
  }
}
```

| Выражение | Условие вызова |
|---|---|
| `all_of(A, B)` | Доступны одновременно `A` и `B` |
| `any_of(A, B)` | Доступна хотя бы одна схема |
| `any_of(all_of(A, B), C)` | Доступны `A` с `B` или одна `C` |
| `security=None` | Операция отключает требование роутера |

В примере у `any_of` одна составная альтернатива, поэтому нужны оба источника. Для
варианта «оба или cookie» добавьте вторую схему: `any_of(all_of(DEVICE_KEY, ACCESS_TOKEN), COOKIE)`.
