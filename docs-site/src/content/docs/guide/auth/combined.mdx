Eazy SDK различает требования AND и OR. `all_of(...)` формирует одну альтернативу, в которой
нужны все credentials. `any_of(...)` выбирает первую полностью доступную альтернативу.

```python
from dataclasses import dataclass

from eazy_sdk import AsyncApi, Http, HttpOperation, op
from eazy_sdk.auth import ApiKeyScheme, BasicScheme, BearerScheme, all_of, any_of

BASIC = BasicScheme("basic")
BEARER = BearerScheme("bearer")
DEVICE_KEY = ApiKeyScheme.header("X-Device-Key", name="device-key")

USER_OR_SERVICE = any_of(BEARER, all_of(BASIC, DEVICE_KEY))

@dataclass(frozen=True, slots=True, kw_only=True)
class ListReports(HttpOperation[list[Report]]):
    __http__ = Http.get("/reports")

@dataclass(frozen=True, slots=True, kw_only=True)
class HealthCheck(HttpOperation[Health]):
    __http__ = Http.post("/health-check", security=None)

class AsyncReportsApi(AsyncApi):
    security = USER_OR_SERVICE

    list_reports = op(ListReports)
    health_check = op(HealthCheck)
```

В этом примере `/reports` принимает либо Bearer token, либо одновременно Basic credentials и
`X-Device-Key`. `/health-check` явно отключает default и остаётся публичной.

| Выражение | Семантика |
|---|---|
| `all_of(A, B)` | Требуются обе схемы `A` и `B` |
| `any_of(A, B)` | Достаточно одной доступной схемы |
| `any_of(all_of(A, B), C)` | Требуются `A` + `B` либо одна `C` |
| `security=None` | Отключить `security` роутера для операции |

Зарегистрируйте providers для всех схем выбранной альтернативы. Если ни одна альтернатива не
может быть разрешена, вызов завершается до сети.
