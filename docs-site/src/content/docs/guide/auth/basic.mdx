`BasicScheme` кодирует пару `(login, password)` и ставит результат в `Authorization`. Пароль
остаётся данными `Identity`, поэтому вызывающий не повторяет его в каждом методе.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2

::::{grid-item}
:class: http-panel http-panel--request

**→ Запрос** · ``GET /auth/basic``

```json
{"headers": {"Authorization": "Basic YWRhOmNvcnJlY3QtaG9yc2U="}}
```
::::

::::{grid-item}
:class: http-panel http-panel--response

**← Ответ** · ``200 OK``

```json
{"credential": "ada"}
```
::::
:::::

Имя `mail-basic` нужно для диагностики. Само значение пары выбирает `BasicScheme`; вручную
собирать или кодировать заголовок не требуется.

:::{warning}
Basic не шифрует пароль. Используйте его только через HTTPS и не выводите заголовок в журнал.
:::
