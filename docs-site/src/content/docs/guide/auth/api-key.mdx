Создайте `ApiKeyScheme` для места, которое выбрал сервер. Пример ниже отправляет ключ в
`X-API-Key` и не добавляет его в публичную сигнатуру `get_reports()`.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2

::::{grid-item}
:class: http-panel http-panel--request

**→ Запрос** · ``GET /auth/api-key``

```json
{"headers": {"X-API-Key": "key-demo-123"}}
```
::::

::::{grid-item}
:class: http-panel http-panel--response

**← Ответ** · ``200 OK``

```json
{"credential": "key-demo-123"}
```
::::
:::::

```{literalinclude} ../../../../../../examples/docs/auth_api_key.py
:language: python
:start-after: "# region docs: auth-api-key"
:end-before: "# endregion docs: auth-api-key"
```

`security=REPORTING_KEY` связывает операцию со схемой. `REPORTING_KEY.static(...)` создаёт
источник значения, а `Identity` передаёт его роутеру во время вызова.

Для параметра запроса замените объявление на
`ApiKeyScheme.query("api_key", name="reporting-key")`. Остальной код не меняется.
