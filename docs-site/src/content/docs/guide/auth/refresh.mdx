`RefreshToken()` отмечает значение для обновления, а `ExpiresAt()` позволяет сделать refresh до
защищённого запроса. Если сервер всё же отвечает `401`, runtime обновляет сессию и один раз
повторяет исходный вызов.

:::::{grid} 1 1 2 2
:class-container: http-exchange
:gutter: 2

::::{grid-item}
:class: http-panel http-panel--request

**→ Запрос** · ``POST /auth/refresh``

```json
{"refresh_token": "refresh-1"}
```
::::

::::{grid-item}
:class: http-panel http-panel--response

**← Ответ** · ``200 OK``

```json
{
  "access_token": "access-2",
  "refresh_token": "refresh-2",
  "expires_at": "2099-01-01T00:00:00Z"
}
```

| Причина refresh | Когда он выполняется | Что происходит с вызовом |
|---|---|---|
| `ExpiresAt()` считает сессию просроченной | До отправки | Запрос уходит один раз с новой сессией |
| Защищённый ответ дал `401` | После первого ответа | Запрос повторяется в пределах `auth_retries` |
| Refresh завершился ошибкой | Во время обновления | Старая revision не заменяется |
