## Порядок выбора адреса

| Приоритет | Источник |
|---|---|
| 1 | Абсолютный URL операции |
| 2 | `base_url` из наиболее точного `bind(...)` |
| 3 | `base_url` роутера или его миксина |
| 4 | `base_url` клиента |

Отдельный клиент нужен, когда сервису требуется другой proxy, TLS-профиль, handler, timeout или
собственная guard-сессия. Передайте его через `bind(Router, client=...)`; в остальных случаях
новый клиент только раздробит cookies, connection pool и управляемое состояние без пользы.

Контрактные defaults роутера включают `security`, `signing`, `crypto`, `wire`, `errors` и
`base_url`. Операция может заменить правила, а `security=None`, `signing=()` и `crypto=None`
явно отключают соответствующее наследование.

`Root(client)` не владеет переданным клиентом. `Root.from_handler(...)` создаёт и закрывает его
сам, а клиент из `bind(..., client=...)` всегда остаётся во владении сборки.
