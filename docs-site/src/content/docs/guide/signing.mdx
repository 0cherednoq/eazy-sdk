вызывающий метод не принимает ключ и не может случайно отправить его как данные запроса.

Runtime сначала строит wire-представление, кодирует и при необходимости шифрует его. Только
после этого signer получает неизменяемый prepared request. Retry и redirect готовят и подписывают
новую попытку заново.

Отсутствующий ключ, неподдерживаемый профиль точных байтов или конфликт двух writers завершают
вызов до отправки. Не выводите ключ, основу подписи с секретными полями или готовую подпись в
журнал приложения.
