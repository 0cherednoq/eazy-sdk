Стратегия пагинации принадлежит классу операции. Обычный вызов возвращает одну страницу, а
`pages()` и `items()` строят следующие запросы через неизменяемое значение операции.


`page=` и `size=` называют поля Python-класса, а не параметры на проводе. `items=` извлекает
элементы, `total_pages=` сообщает последнюю страницу. Несовпадающий тип результата или опечатка
в имени поля останавливает объявление роутера при импорте.

## Выбрать стратегию

| Стратегия | Поле следующего запроса | Признак окончания |
|---|---|---|
| `Pages.numbered` | Номер страницы | Общее число страниц, короткая или пустая страница |
| `Pages.offset` | Смещение | Общее число элементов, короткая или пустая страница |
| `Pages.cursor` | Cursor из ответа | Отсутствующий следующий cursor |
| `Pages.next_url` | Готовая ссылка | Отсутствующая ссылка |

`items()` разворачивает страницы в один поток. Аргумент `key=` пропускает повторяющиеся элементы
и завершает обход, если новая страница не добавила ни одного значения. `max_pages=` ограничивает
число запросов, а `options=` применяется к каждой странице.

Каждая страница проходит обычные retry, middleware, авторизацию, защиту и подпись. Синхронный
роутер возвращает iterator, асинхронный async iterator.
