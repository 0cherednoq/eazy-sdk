Что именно доказал тест?

Хороший тест вызывает тот же публичный метод, который использует приложение. Локальный handler
принимает подготовленный запрос и возвращает детерминированный ответ, поэтому проверка не зависит
от внешнего сервиса.

получает модель `Message`. Реальный тест сравнивает эти значения средствами выбранного test
runner; транспортная обвязка остаётся общей fixture.

## Выбрать уровень проверки

| Уровень | Что подтверждает |
|---|---|
| Импорт деклараций | Контракты компилируются и типы согласованы |
| `prepare(...)` | Точные method, URL, headers и body без отправки |
| Локальный handler | Полный request/response pipeline и ошибки |
| Локальный сайт | Несколько связанных вызовов, cookies, refresh и replay |
| Реальный браузер | DOM, навигация, handlers и состояние контекста |

Для подписанных или зашифрованных запросов проверяйте окончательные байты через recording
handler, а открытые данные на стороне локального сайта. Не подменяйте compiler или executor:
иначе тест подтверждает отдельную тестовую ветку, которой нет у пользователя SDK.

:::{note}
Публичная сеть подходит для отдельного opt-in smoke test. Основной набор должен работать
детерминированно и не зависеть от чужих credentials, rate limits или доступности сервиса.
:::
